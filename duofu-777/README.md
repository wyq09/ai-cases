# duofu-777 多福巨奖

单文件 H5 复刻澳门赌场「多福巨奖 / Duo Fu Duo Cai」5×3 243 路老虎机，含四大奖池、福娃选奖、免费局与金身玩法。零依赖、离线可玩，手机桌面浏览器均可直接打开 `index.html`。

## 玩法

- 5 轮 × 3 行 243 路：符号从最左轮相邻连出即中奖，任意行位组合各算一路，每路赢分 = 赔付 × 押注 ÷ 12
- 押注 5 档 8/18/38/68/88：档位解锁金身符号（金蟾→金鱼→金龟→金元宝），档5 全开且中奖 ×1.2
- 金身落桌填充对应奖池轨道；任一轨道填满进入「福娃选奖」：12 枚金币翻出 3 枚相同奖名即中该奖池（多福巨奖 / 多财大奖 / 多福中奖 / 多福小奖）
- 任意位置 3 个金锣触发 10 次免费局（剔除 10/J/Q、再中 3 锣 +10 次）
- 福 WILD 出现在 2/3/4 轮，替代除金锣外任意符号
- 自动旋转（10/25/50/100/∞）、拍停、快速模式、大奖/超级大奖演出
- 积分 / 奖池 / 轨道 / 配置全部 localStorage 持久化，刷新不丢；离线时奖池缓慢上涨
- 游戏内配置面板（菜单 → 游戏配置）：17 个图标逐一上传替换、21 种音效自定义与音量、押注档/轨道/免费局/中奖倍率等玩法参数、配置导出导入

## 技术要点

- **纯程序化资产**：全部符号/背景/LOGO 为运行期生成的 SVG data URI，音效为 WebAudio 合成（五声音阶古筝风 BGM + 21 个 cue），无任何外部资源
- **数学模型**：滚轮条 60 格加权 + 金身专格 + 福锣间隔约束；100 万局稳态模拟 RTP ≈ 94.5%（base 46% / 免费局 24% / 奖池 24%），选奖结果按官方口径预定、分布可配
- **滚轮引擎**：DOM 回收格 + rAF 虚拟滚动（transform-only），落点减速/过冲回弹、逐轮错停、拍停；rAF+定时器双驱动防后台节流冻结
- **移动端**：100dvh 布局、safe-area、竖屏双排按键、配置面板底部抽屉、touch-action 防误触缩放

## 开发

```bash
python3 build.py   # src/*.js + src/shell.html -> 单文件 index.html
```

调试参数：`?reset=1` 清档，`?rig=win|bigwin|fs|gold` 强制中奖/免费局/金身，`?bet=88` 设押注，`?auto=N` 自动 N 局，`?muted=1` 静音；`window.__df` 暴露状态与测试钩子。
