# 跳一跳

微信《跳一跳》的非官方 H5 复刻。单文件、无外部依赖，手机和电脑均可离线游玩。

## 玩法

- 按住屏幕或鼠标蓄力，松手起跳；电脑也支持空格键。
- 普通落地 +1，连续落在中心依次 +2、+4、+6……。
- 井盖、魔方、便利店、唱片停留约 2 秒，分别额外获得 5、10、15、30 分。
- 最高分、最近战绩和稳定落地进度保存在本地；刷新后可选择继续。
- 首页可开启自动演示，演示成绩不计入个人纪录。
- 设置支持难度、蓄力速度、声音、辅助线、背景颜色及 JSON 配置导入导出。

## 技术要点

- **画面**：Canvas 2D 等距平台与黑色棋子，程序化生成六类平台。
- **运动**：按压时长映射距离、抛物线轨迹、落点判定、相机平滑跟随。
- **音效**：WebAudio 合成蓄力、跳跃、连击和奖励声音。
- **状态**：设置与战绩分开存储，切后台/打开设置暂停游戏。
- **规则边界**：物理参数、出现概率及奖励数值为复刻设定，不代表已核实的原版精确实现，参见 [规则资料](ref/rules-spec.md)。

## 开发

```sh
python3 build.py
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`，也可直接打开 `index.html`。调试参数：`?seed=37`、`?autoplay=1`、`?muted=1`、`?reset=1`（仅清除此游戏本地记录）。

浏览器功能验证结果见 [browser-test.json](ref/browser-test.json)。已验证真实按压得分、连击、特殊奖励、失败重开、配置持久化、继续游戏和自动演示。已生成横竖屏截图并检查页面无横向溢出；当前模型不支持图像输入，未完成视觉审查或像素级对照。设置中的平台贴图上传目前仅保存配置，基础渲染版本未应用贴图。
