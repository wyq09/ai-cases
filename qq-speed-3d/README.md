# QQ飞车 · 极速海岸 3D

Three.js 单页 3D 卡丁车竞速，向《QQ飞车》的漂移手感与演出节奏致敬：**7 条主题赛道 + 程序化无限赛道 + 5 种道具攻防 + 三档难度 + 五部件改装工坊**，海岸、峡谷、霓虹都市、雪原、雨林、火山、云端各自一套配色、地形与氛围；漂移三段蓄力、松手喷火接双喷、三格氮气、加速带、问号道具箱与实时排名。所有贴图、模型、粒子、音效均在运行时程序化生成，零外部素材。

## 玩法

### 驾驶

- **漂移**：转向中按住 `Shift`，车尾甩出、轮胎冒火花；蓄力分青 / 紫 / 橙三段，段位提升有音效与镜头微震
- **松手喷**：松开漂移立即点火，按蓄力段位给 0.55s ~ 1.15s 加速；**0.55 秒内再按一次 Shift 触发双喷**
- **氮气**：漂移与加速带积攒三格氮气，`空格` 点火；氮气期间尾焰转青蓝、FOV 拉宽、速度线增强
- **完美起步**：倒数到 1 时按漂移 / 空格，开局弹射
- **赛道**：撞墙擦出火花并掉速、草地明显减速；每条赛道有独立圈数、加速带与道具箱布局

### 道具

穿过赛道上的**问号箱**随机获得一件道具，按 `E`（手机上直接点 HUD 道具格）使用：

| 道具 | 效果 |
| --- | --- |
| 氮气引擎 | 立即爆发加速 1.6 秒，并补充少量氮气 |
| 追踪导弹 | **自动锁定全场第一名**，跨圈追击（目标越远飞得越快），命中后使其打滑减速 |
| 燃油地雷 | 在车后布雷，追兵碾过会打滑 |
| 能量护盾 | 8 秒内抵挡一次导弹 / 地雷 / 电磁攻击 |
| 电磁风暴 | 干扰全部对手，集体打滑掉速 |

- 导弹目标规则：永远先锁「第一名」（玩家自己领跑时改锁最前面的追兵），锁定期间目标头顶有旋转瞄准环（第一名为金色）
- 名次越靠后越容易抽到进攻性道具，领跑时更容易抽到地雷与护盾
- AI 对手会在被追击时布雷；被击中会原地打转、踩烟、掉速
- 道具格、护盾条、拾取提示、全屏受击 / 护盾 / 电磁闪光均有独立 HUD 反馈

### 难度

标题页与选关页都能切换，三档即时生效并写入存档：

| 难度 | AI 速度 | 你的极速 | 氮气/漂移充能 | 金币 | 星级 |
| --- | --- | --- | --- | --- | --- |
| 低 EASY | ×0.91，队尾更散 | ×1.08 | ×1.3 | ×0.75 | 前 3 名都是 3 星 |
| 中 NORMAL | ×1.00 | ×1.00 | ×1.0 | ×1.00 | 冠亚季 = 3/2/1 星 |
| 高 HARD | ×1.09，队尾更紧 | ×0.97 | ×0.82 | ×1.60 | 只有冠军 3 星（亚军 1 星，季军以下无星） |

- AI 的「追赶玩家」幅度也随难度变化（低 9% / 中 13% / 高 19%），高难度下 AI 布雷更频繁
- 星级表按难度分三档：`低 [3,3,3]` / `中 [3,2,1]` / `高 [3,1,0]`（对应冠军/亚军/季军）
- 难度同时缩放速度条归一化与结算面板，HUD 迷你地图下方常驻 `难度 X · 改装 Lv.N`

### 改装（TUNING GARAGE）

标题页 / 选关页点「改装」打开工坊，花**金币**升级五个部件，每件 3 级：

| 部件 | 效果 | 外观 |
| --- | --- | --- |
| 引擎 ENGINE | 极速上限 +2.5%/级，起步更快 | 尾翼变高 |
| 涡轮 TURBO | 喷气时长 +12%/级，氮气更持久 | 排气更粗、尾焰更旺 |
| 轮胎 TIRES | 抓地 +8%/级，漂移蓄力更快 | 轮圈发光、轮胎加宽 |
| 尾翼 AERO | 撞墙保留速度更高，导弹更快更疼 | 尾翼加宽加高 |
| 涂装 PAINT | 抽道具更幸运（进攻道具概率↑） | 车底霓虹光（满级转粉） |

- 升级消耗金币：160 / 380 / 820 一档（各部件略有差异），满级显示 `MAX`
- 金币不足时按钮变灰、点击只提示差额，不会误扣
- 所有数值集中在一个 `tuningStats()` 里，物理、道具、HUD 全部读它，改装立即生效（含比赛中途重新开始）
- 改装等级与难度一起写入 `localStorage`，`?reset=1` 才会清空

### 关卡

- 结算页展示星级、赛道、道具命中数、新纪录与解锁提示，可直接「下一关」

### 无限赛道

- 每一阶段用程序生成一条**全新的闭环赛道**（半径、弯型、海拔、主题随阶段变化），无需加载
- 每阶段 2 圈，**前 4 名晋级**；被淘汰或主动结束都会进入挑战结算
- 关卡顶部显示 `STAGE`、地图标题显示当前主题，金币按阶段结算，历史最佳阶段写入存档
- 暂停菜单可「结束无限挑战」；重新开始会从第 1 阶段重新生成种子

### 成长

- 完赛按名次、关卡难度与难度系数获得金币；金币可用于改装升级
- 累计金币、难度、改装等级、每关最佳成绩、星级、通关进度、无限赛道最佳阶段写入 localStorage
- 画质三档、静音状态同样持久化；`?reset=1` 可清空存档

## 技术要点

- **纯程序化资产**：Canvas 生成沥青 / 草地 / 沙地 / 雪 / 熔岩 / 看台人群 / 广告牌 / 天空盒 / 问号箱 / 赛道横幅，无一张外部贴图
- **主题赛道**：环状 CatmullRom 曲线 → 带状网格生成路面、路肩红白条、护墙与草坡；弯道、高低起伏、加速带、道具箱全部由同一条曲线派生。主题配置统一驱动天空 / 雾 / 海水 / 地形 / 城市 / 植被 / 天气
- **无限赛道**：随机极坐标闭环（保证不自交）+ 半径平滑；每阶段复用同一套构建器，旧场景 `dispose()` 回收几何与材质，地形纹理按主题缓存
- **道具系统**：问号箱拾取、加权掉落、追踪导弹（**锁定第一名** + 距离自适应追赶速度 + 目标头顶瞄准环 + 地形高度钳制）、地雷、护盾、电磁风暴；AI 会动态布雷、被打滑、踩烟，护盾有球形护罩与 HUD 计时
- **难度 / 改装**：`DIFFICULTIES` 与 `PARTS` 是两张纯数据表，`applyLoadout()` 把它们合成唯一的 `mods`（极速上限、加速、抓地、充能、喷气、布雷率、导弹参数、幸运值），物理与道具只读 `mods`；`applyKartTuning()` 再把改装等级映射到尾翼/排气/轮圈/车底光等几何与材质，升级看得见
- **漂移物理**：车头朝向与速度方向分离，漂移时抓地力降低产生甩尾；蓄力值驱动火花颜色、漂移条、音效段位与松手加速
- **打击感**：碰撞 hitstop 顿帧 + 镜头抖动 + 火星粒子 + 低频撞击音；撞墙持续刮擦火花；氮气 / 双喷有独立 FOV 与速度线强度
- **粒子 / 天气**：自定义 ShaderMaterial 点精灵池（加法混合火花 + 普通混合烟尘），对象池复用；雪原飘雪、火山落灰为跟随相机的粒子场
- **音效**：WebAudio 全合成——双振荡器引擎（转速随速度变调）+ 噪声胎噪 / 风噪 / 草地 / 氮气循环，漂移段位提示音、双喷、道具拾取 / 导弹 / 爆炸 / 护盾 / 电磁 / 地雷、倒计时、完赛与阶段号角，另有一轨 128 BPM 合成器 BGM
- **演出**：起步灯、倒计时、名次 / 圈数弹跳、超车提示、终点撒花、结算面板、迷你地图实时车辆 / 道具箱位置、无限赛道 Stage 转场
- **移动端**：双指触控（方向 + 漂移独立 pointerId）、safe-area、道具格 / 护盾条 / 竖屏横屏桌面三套 HUD 布局
- **性能**：InstancedMesh 渲染护墙 / 棕榈 / 松树 / 仙人掌 / 轮胎 / 城市 / 看板 / 灯塔 / 道具箱 / 遗迹；阴影相机跟随玩家，画质三档（DPR / 阴影 / 粒子密度）

## 运行

ESM + importmap，需要静态服务器（不能 `file://` 直开）：

```bash
cd qq-speed-3d && python3 -m http.server 8791
# 打开 http://localhost:8791  手机访问 http://<局域网IP>:8791
```

> 维护提示：更新 JS 后请同步递增 `index.html` 的 importmap / module `?v=` 与 `src/*.js` 相对 import 的版本号（当前 `20261018a`），避免 7 天静态缓存读到旧模块。

调试参数：

- `?auto=1` 自动开局
- `?level=neon` 指定开局赛道（`coast` / `canyon` / `neon` / `frost` / `jungle` / `volcano` / `sky`）
- `?endless=1` 配合 `auto=1` 直接进入无限赛道
- `?unlock=1` 解锁全部关卡（测试用）
- `?diff=easy|normal|hard` 强制难度（不写存档）
- `?quality=low|medium|high` 强制画质、`?muted=1` 静音、`?reset=1` 清空存档

## 验收

全部使用 **ego-lite** 浏览器自动化：

```bash
# 基础竞速 / 漂移 / 氮气 / 结算 / 移动端
ego-browser nodejs < test/ego-acceptance.js

# 7 条关卡 / 5 种道具 / 无限赛道晋级与淘汰 / 解锁 / 手机布局
ego-browser nodejs < test/ego-levels-items.js

# 难度三档 / 改装工坊（购买、满级、外观、存档）/ 导弹锁定第一名 / 结算金币与星级 / 手机布局
ego-browser nodejs < test/ego-difficulty-garage.js

# 转向方向与护栏包络
ego-browser nodejs < test/regression.js
```

说明：

- 验收脚本统一复用常驻 TaskSpace「QQ飞车 3D 测试」的 `p1`，只关掉自己额外开的页面，不整片清空标签页；跑完 `p1` 仍留在测试页上可直接复用（ego 的标签页/渲染进程堆积会让截图与 CDP 超时）
- ego 窗口被遮挡时 `requestAnimationFrame` 会节流，涉及逐帧玩法的断言统一通过 `window.__qq.tick(dt, steps)` 主动推进模拟帧，截图前再留真实渲染时间
- `test/ego-levels-items.js` 覆盖：选关锁定、7 条赛道构建、道具拾取 / 5 种道具效果 / 护盾抵挡 / 受击打滑、无限赛道连续晋级、主动结束、淘汰结算、关卡三星与解锁、下一关、桌面与手机无溢出、道具 HUD 不遮挡触控
- `test/ego-difficulty-garage.js` 覆盖（20 项）：三档难度的极速/AI 速度/金币/星级差异、工坊开关与金币不足拦截、五部件购买与等级上限、改装外观变化（车底光 / 尾翼高度）、难度与改装存档持久化、改装极速上限实际生效、导弹锁第一名 / 命中 / 玩家领跑改锁追兵、HUD 与结算显示难度改装、手机工坊与 HUD 布局
- 测试截图输出在 `test/*.png`（已 gitignore）
- 调试钩子：`window.__qq`（`tick` / `startLevel` / `startEndless` / `giveItem` / `useItem` / `forceStageClear` / `debug` …）
- 浏览器 HTTP 缓存可能让测试/截图读到旧模块。需要完全可复现时，先用无缓存服务器启动一份：

```bash
python3 test/serve-nocache.py 8795 .
QQ_URL=http://127.0.0.1:8795/ ego-browser nodejs < test/ego-levels-items.js
QQ_URL=http://127.0.0.1:8795/ ego-browser nodejs < test/ego-shots.js
```
