# QQ飞车 · 极速海岸 3D

Three.js 单页 3D 卡丁车竞速，向《QQ飞车》的漂移手感与演出节奏致敬：海岸环岛赛道、6 车同场、漂移三段蓄力、松手喷火接双喷、三格氮气、加速带与实时排名。所有贴图、模型、粒子、音效均在运行时程序化生成，零外部素材。

## 玩法

- **漂移**：转向中按住 `Shift`，车尾甩出、轮胎冒火花；蓄力分青 / 紫 / 橙三段，段位提升有音效与镜头微震
- **松手喷**：松开漂移立即点火，按蓄力段位给 0.55s ~ 1.15s 加速；**0.55 秒内再按一次 Shift 触发双喷**
- **氮气**：漂移与加速带积攒三格氮气，`空格` 点火；氮气期间尾焰转青蓝、FOV 拉宽、速度线增强
- **完美起步**：倒数到 1 时按漂移 / 空格，开局弹射
- **赛道**：3 圈 · 9 个加速带 · 5 名 AI 对手 · 撞墙擦出火花并掉速、草地明显减速
- **成长**：完赛按名次得金币，最佳单圈 / 历史最佳 / 画质 / 静音写入 localStorage

## 技术要点

- **纯程序化资产**：Canvas 生成沥青 / 草地 / 沙地 / 看台人群 / 广告牌 / 起点横幅 / 天空盒，无一张外部贴图
- **赛道**：CatmullRom 闭环采样 → 带状网格生成路面、路肩红白条、护墙与草坡；弯道、高低起伏、加速带全部由同一条曲线派生
- **漂移物理**：车头朝向与速度方向分离，漂移时抓地力降低产生甩尾；蓄力值驱动火花颜色、漂移条、音效段位与松手加速
- **打击感**：碰撞 hitstop 顿帧 + 镜头抖动 + 火星粒子 + 低频撞击音；撞墙持续刮擦火花；氮气 / 双喷有独立 FOV 与速度线强度
- **粒子**：自定义 ShaderMaterial 点精灵池（加法混合火花 + 普通混合烟尘），对象池复用，无逐帧分配
- **音效**：WebAudio 全合成——双振荡器引擎（转速随速度变调）+ 噪声胎噪 / 风噪 / 草地 / 氮气循环，漂移段位提示音、双喷、撞击、倒计时、完赛号角，另有一轨 128 BPM 合成器 BGM
- **演出**：起步灯、倒计时、名次 / 圈数弹跳、超车提示、终点撒花、结算面板、迷你地图实时车辆位置
- **移动端**：双指触控（方向 + 漂移独立 pointerId）、safe-area、竖屏 / 横屏 / 桌面三套 HUD 布局
- **性能**：InstancedMesh 渲染护墙 / 棕榈 / 轮胎堆 / 看台，阴影相机跟随玩家，画质三档（DPR / 阴影 / 粒子密度），实测 Apple M1 Max 120fps

## 运行

ESM + importmap，需要静态服务器（不能 `file://` 直开）：

```bash
cd qq-speed-3d && python3 -m http.server 8791
# 打开 http://localhost:8791  手机访问 http://<局域网IP>:8791
```

调试参数：`?auto=1` 自动开局、`?quality=low|medium|high` 强制画质、`?muted=1` 静音、`?reset=1` 清空存档。

## 结构

```
index.html            页面骨架、HUD / 标题 / 结算 / 触控 UI
src/main.js           渲染循环、比赛状态机、驾驶物理、AI、相机、特效调度
src/track.js          赛道曲线采样与全部场景几何（海面 / 岛 / 城市 / 看台 / 广告牌 / 灯塔）
src/kart.js           程序化卡丁车（车体 / 人偶 / 车轮 / 尾焰 / 软阴影）与动画
src/particles.js      点精灵粒子池 + 胎痕 InstancedMesh
src/textures.js       Canvas 贴图工厂（路面 / 草地 / 人群 / 天空盒 / 广告牌 / 火焰）
src/audio.js          WebAudio 引擎、音效、BGM
src/hud.js            HUD、迷你地图、速度线、结算
src/input.js          键盘 / 触屏 / 测试用模拟输入
vendor/               three r170（离线可用）
shots/                桌面 / 手机实拍截图（菜单、比赛、漂移、氮气、结算）
test/full.py          Playwright 双视口功能验收
test/viewports.py     四视口布局检查
test/shot.py          单视口快速截图
test/ego-acceptance.js  ego-browser 验收脚本
test/regression.js     转向方向 + 护栏包络回归
```

## 验收

Playwright（桌面 1440×900 + iPhone 390×844）：

```bash
python3 test/full.py
```

ego-browser：

```bash
ego-browser nodejs < test/ego-acceptance.js
```

覆盖：启动、菜单、真实点击开局、比赛运行、漂移蓄力、松手喷、双喷、氮气、完赛结算与存档、重开、暂停 / 恢复、无 console 报错、无页面溢出。ego 套件连跑 5 次全绿。
