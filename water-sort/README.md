# 倒水挑战 · Water Sort Puzzle

经典倒水排序益智 H5 复刻：点击拿起瓶子、再点目标瓶倾倒，把同色水聚满整瓶，全部归色即过关。无限关卡（程序化生成 + 求解器验证必可解），手机竖屏优先，单文件零外部资源。

[在线游玩](https://case.youyongai.com/water-sort/)

## 玩法

- 点击瓶子拿起，再点另一瓶倾倒：目标瓶为空或顶色相同才可倒，同色满瓶即完成一色
- 全部瓶「空或纯色」过关，右上角实时显示归色进度百分比
- 底部工具条：撤销（无限步回退）、提示（求解器自动演示一步）、加瓶（每关限次的破局空瓶）、重开（同关同布局）
- 过关按步数评 1~3 星，记录每关最佳步数；关卡难度随颜色数递增（3 色 → 10 色，每 7 关降档喘息）
- 暂停菜单：继续 / 重玩 / 跳过此关 / 设置 / 回到封面
- 设置面板：瓶容量、空瓶数、色数上限、加瓶次数、动画速度、提示开关；三套房间配色与三套水色板；音效逐条上传替换（≤3MB）；配置导出导入、进度清空

## 技术要点

- **无限关卡生成**：mulberry32 种子确定每关布局（同关刷新/续玩一致），随机分装后经 DFS 求解器（状态规范化 + 剪枝 + 启发式排序）验证必可解，不可解自动重摇
- **同一求解器三用**：生成验证 / 提示按钮下一步 / AI 自动演示（`?demo=1` 挂机连过关，卡死自动撤销重摇）
- **Canvas 倒水演出**：SVG 瓶形 Path2D 裁剪液体、层间暗线与液面高光、拿起—飞移—绕瓶口旋转—液流曲线—落点液滴的全流程动画；rAF + setInterval 双驱动防后台节流冻结
- **全程序化资产**：房间/三猪观战（idle 浮动、过关齐跳）/骑摩托猪/logo/玻璃瓶/图标全部 SVG data URI 离屏预渲染；10 种音效 + 八音盒 BGM 全 WebAudio 合成
- 手机竖屏 / 横屏 / 桌面三形态自适应，safe-area 适配，进度与配置 localStorage 持久化
