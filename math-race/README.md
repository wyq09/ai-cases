# 口算竞速场 · MATH RACE

小学生分年级口算竞赛：**同一个房间、同一个倒计时、各做各的题**。手机答题，教室大屏同步直播赛道，先冲线者胜。

一 ~ 四年级同场竞技也不吃亏——每个人的题目按自己年级的人教版进度生成，题量按年级配平，比的是「完成自己那份的速度」。

## 玩法

- **房主**：首页填昵称 → 选年级 → 创建房间，得到 8 位房间号；大厅可切主题（跑道 / 龙舟）、时长（2 / 3 / 5 分钟），可移出捣乱的同学。
- **选手**：手机扫码，或在首页输房间号加入；加入时选自己的年级（决定题目难度），大厅里也能点头像徽章随时改。
- **大屏**：大厅点「大屏」，投影出二维码 + 房间号；开赛后变成实时赛道，每个选手一条跑道。
- **答题**：倒计时 3-2-1 后开赛，纯数字键盘输入（不需要负号小数点），答对前进，答错原地并记入错题。
- **结算**：先完赛的排前面；全部冲线或时间到即结算，领奖台 + 名次表 + 个人错题回顾（附正确答案）。
- **再来一局**：房主一键重开，清空进度但保留房间和成员。

## 分年级题库（对齐人教版进度）

| 年级 | 题型 | 题量 |
| --- | --- | --- |
| 一年级 | 10 / 20 以内加减（含进位退位）、100 以内不进位、整十数加减 | 15 |
| 二年级 | 100 以内进位加 / 退位减、表内乘除（口诀求商）、百内连加减 | 12 |
| 三年级 | 万以内加减、多位数 × 一位数、两位数 × 两位数、除数一位数除法、两步混合 | 10 |
| 四年级 | 三位数 × 两位数、除数两位数除法、大数加减、含括号四则混合、三步混合 | 8 |

答案恒为非负整数：除法先定商与除数再反推被除数，混合运算按模板构造，保证结果不下溢。

## 技术要点

- **零依赖单进程**：`node:http` 托管静态页 + REST + SSE，`node:sqlite`（Node 22+ 内置）每房间一行 JSON 持久化；重启后按房间号恢复。
- **答案不出服务端**：出题是 `genQuestion(grade, seed)` 的纯函数（FNV-1a + mulberry32），服务端用 `房间seed:玩家token:题号` 复算答案，客户端只拿到题面。断线重连题目不丢，同房间不同玩家题目互不相同。
- **SSE + 轮询兜底**：实况推送优先走 EventSource，连续失败 3 次自动降级为 2 秒轮询；广播按 120ms 合并窗口防抖。
- **服务端时间校准**：倒计时以 `serverNow` 对齐本地时钟，避免手机时间不准导致抢跑或误判。
- **单文件前端**：`src/*.js` 模块化开发，`build.py` 内联成 `client/index.html`（约 110 KB，零外部资源）。
- **全程序化美术**：角色 / 龙舟是内联 SVG，二维码用内置 `qrcode.js` 生成，音效是 WebAudio 实时合成（答对、答错、倒计时、冲线）。
- **移动优先**：手机竖屏答题区 + 键盘常驻底部，安全区适配；横屏（平板/手机横放）自动切成「题目在左、键盘在右」的双栏布局，整屏不滚动；大屏端点击画面可全屏投影。

## 运行

**在线**：<https://case.youyongai.com/math-race/>

本地：

```sh
cd math-race
python3 build.py                       # src/ → client/index.html
node server.js                         # http://127.0.0.1:8787/math-race/
```

环境变量：`PORT`（默认 8787）· `BASE_PATH`（默认 `/math-race`）· `DB_PATH`（默认 `data/rooms.db`）· `MAX_ROOMS`（默认 200）。

## 部署

带后端的案例独立端口、独立部署，不进静态站托管。生产环境：

```
浏览器 ──HTTPS──> nginx (case.youyongai.com)
                    └─ /math-race/ ──proxy──> 127.0.0.1:8787 (systemd: math-race)
                                                 └─ SQLite: /var/lib/math-race/rooms.db
```

- **代码**：GitHub Actions 把仓库 rsync 到 `/data/ai-cases/`，然后重启 `math-race` 服务。
- **数据库**：放在 `/var/lib/math-race/`，在 rsync 目录之外，`--delete` 不会清掉房间数据。
- **进程**：`deploy/math-race.service`（systemd，`Restart=always`，开机自启，`ProtectSystem=full`）。
- **反代**：`deploy/nginx-math-race.conf` 由 `case.youyongai.com.conf` include；SSE 已关闭 `proxy_buffering` 并放长超时。

首次部署或修改 unit/nginx 后，在服务器上执行一次：

```sh
ssh ubuntu@175.178.188.217
cd /data/ai-cases/math-race && bash deploy/install.sh
```

`install.sh` 幂等：重复执行只更新 unit 与 nginx 片段并重启服务，不会清库。

日常发布只需推 `main`，CI 自动完成 rsync + 重启 + 健康检查。

运维命令：

```sh
sudo systemctl status math-race
sudo journalctl -u math-race -f
curl -fsS https://case.youyongai.com/math-race/api/health
```

## 测试

```sh
node test/run.mjs
```

两部分，共 **48099 项断言**，当前全绿：

1. **出题引擎**：每个年级 3000 题，用独立表达式求值器交叉验证答案、题面字符集、非负整数、题型覆盖度、同 seed 确定性。
2. **服务端 API**：起真实进程打 HTTP，覆盖建房 / 加入 / 踢人 / 改设置 / 开赛权限 / 倒计时内拒答 / 防连点限速 / 重复题号幂等 / 答错回传正确答案 / 错题记录 / 全员完赛自动结算 / SSE 推送与反代头 / 重启后 SQLite 恢复 / 房主退出解散。

UI 端到端（ego-lite 真实浏览器，三端联动）：首页 → 建房 → 大屏二维码 → 两名不同年级学生扫码加入 → 3-2-1 倒计时 → 全程答题 → 冲线 → 领奖台与错题回顾 → 再来一局，全流程通过；iPhone 竖屏 390×844 与横屏 844×390 均无溢出。

## 已修复的验收问题

这轮真实浏览器验收发现并修掉了 5 个测试覆盖不到的缺陷：

1. **完赛头像被裁**：冲线后头像跑到 92% 并向右溢出赛道，大屏上名字被截成「小…」。
2. **「完赛」标签压线且竖排**：百分比文字没有 `white-space: nowrap`，在窄跑道上被折成两行。
3. **跨年级实时名次错误**：名次按答对题数排序，四年级（8 题）全对会排在一年级（15 题）答对 14 题之后；改为先比完赛时间、再比完成比例。
4. **结算页显示 `undefined`**：前端读 `p.correct`，接口字段却是 `p.progress`。
5. **大屏大厅布局塌陷**：`.big-body` 用横向 flex，等待文案被挤到右上角。

另外补了平板/手机横屏的双栏答题布局（原横屏键盘被截断）。

## 已知边界

- 房间号是 8 位数字，同一时间最多 200 个房间、每房间 32 人。
- 无人连接的大厅 6 小时后回收，已结束的房间保留 30 分钟。
- 断线重连靠 `localStorage` 里的房间 token，换设备或清缓存会丢身份（需重新加入）。
