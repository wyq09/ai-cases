# 祖玛 · 无尽遗迹

经典祖玛玩法的单文件 H5 实现，暖棕石刻神庙主题，离线可玩。

## 玩法

- 点击或拖动瞄准，松手发射；三个及以上相邻同色珠消除。
- 消除后的同色断口回吸，形成连锁和倍数奖励。
- 点击青蛙、换球按钮或空格交换当前球与下一球。
- 每关有两次爆破弹和两次八秒缓行，无广告、无微信胶囊。
- 清空全部珠子进入下一关；珠链抵达终点则重新挑战。
- 关卡无预设终点，六类轨道与镜像循环，出球按关卡种子生成；颜色数、珠数和速度递增后封顶，避免无限堆速。
- 设置中支持瞄准辅助、声音、触觉反馈和自动演示。

## 技术要点

- **球链**：弧长路径、分步弹道碰撞、插入推挤、断口回吸与连锁消除。
- **适配**：横竖屏使用不同世界尺寸，旋转时按路径进度重映射，不重开关卡。
- **手感**：发射回坐、珠子滚动、消除碎片、扩散环、飘分、轻微震屏及 WebAudio 合成音效。
- **存档**：关卡、得分、珠链和道具自动保存在本地。切后台暂停；胜利后刷新进入下一关。
- **性能**：静态背景和珠子纹理离屏缓存，DPR 上限 2，无外部资源。
- **视觉说明**：本次模型无法读取附件图像内容。美术为近似的经典祖玛主题，未完成参考截图/录屏的一比一还原或视觉验收。

## 开发

```sh
python3 build.py
python3 -m http.server 8769
```

打开 `index.html` 或本地 HTTP 页面。`shell.html` 是构建模板，不是运行入口。`?test=1` 开放测试场景钩子并跳过失焦自动暂停。
