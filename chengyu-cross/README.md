# 填成语 · 十字填字

微信小游戏「填成语」复刻：深紫底十字成语填字——点空格、点候选字，填对变绿、填错扣次数；无限关卡系统自动出题，支持导入自定义成语词库并做连通性可行性分析。单文件零外部资源，离线可玩。

## 玩法

- 每关一张由 4 字成语纵横交叉的字谜：米白格=预给字，紫色空格=待填，点空格选中（橙框）再点底部候选字
- 填对后光标自动**顺延到当前成语的下一个空位**；本成语填完自动**流转到交叉的下一条成语**，一条接一条顺着填
- 填对变绿并计入「成语」总数；累计填对到达里程碑（默认 1/3/14 个）发放金币；填错抖动红闪、剩余次数 −1
- 次数耗尽弹失败窗：花金币补次数 / 重新开始本关；全部填完过关进下一关，关卡无限（同关种子确定性，刷新不变）
- 菜单：提示（花金币自动填一格）、重新开始本关、跳关、自定义词库导入、设置
- **自定义导入**：粘贴成语列表 → 自动分析三步（合法性 → 共字连通性并查集 → 交叉摆放求解），报告「✓可行子集（附谜面预览）/⚠位置冲突/✗孤立词/✗非法词」，一键采用可行子集开玩
- **设置可调**：每关词数/增长节奏/上限、预给字比例、剩余次数、网格跨度、里程碑与金额、提示与补次数价格、音量、减弱动效、出题词库切换、配置导出导入、清档
- 大网格放不下时棋盘**可拖拽/滚轮平移**（选中格自动带进可视区）；候选字随数量自适应缩小、候选区限高不挤压棋盘；手机/iPad/桌面自适应（iPad 舞台加宽至 640px、格与字块同步加大），横屏棋盘居左候选字居右列

## 技术要点

- **出题引擎**：种子随机 + 交叉机会点贪心扩张（词首尾禁粘连、侧向禁贴边、跨距约束、紧凑度偏置），40 次重试取最优；`validateGrid` 独立复核（交叉冲突/贴边/连通性）
- **可行性分析**：合法性 → 并查集孤立词识别 → 多种子摆放求解（迭代/耗时双预算、跨度随池自适应），保留最大可行子集；换摆法加盐可复现
- 词库 2076 条常用成语 + 1068 字频序表（高频字覆盖度决定出题率），全程序化 WebAudio 音效（拨弦/木鱼/BGM），单文件 145KB 零外部资源
- 候选池 = 全部待填字 + `n/2+1` 干扰字；金币/进度/配置/自定义词库分 key 持久化，`?reset=1` 清档
- 布局自适应：竖屏上下结构、横屏矮视口棋盘居左候选字居右列；`rAF` 二次校准网格尺寸
- 并行子代理开发：契约先行（`src/contract.md`），词库/音效/设置面板三代理并行，主线管引擎/状态机/集成

