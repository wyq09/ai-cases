# 挪挪车 · 无限关卡版 需求文档

> 交付给 AI 编码代理（Codex）实现的完整需求。按本文档从零实现，所有规则数值以本文档为准，不做臆测。

## 0. 一句话概述

竖屏 H5 小游戏：拥堵的停车场里每辆车只能沿车头箭头方向前进，点击车辆让它滑动/冲出停车场去接走排队的乘客；关卡由程序化生成、无限关、保证有解；配 5 种道具与金币经济。

## 1. 技术约束（必须遵守）

- **单文件交付**：新建 `index.html`，CSS/JS 全部内联，零构建、零依赖、零网络请求。
- **零资源文件**：不放任何图片/音频文件——车辆、小人、图标全部用 Canvas 程序化绘制，音效用 WebAudio 合成。
- 竖屏 9:16 布局，移动端优先；桌面浏览器居中显示手机比例容器（max-width ≈ 480px），可正常游玩。
- 渲染：主棋盘用 Canvas 2D（devicePixelRatio 适配），弹层/按钮用 DOM。
- 存档：`localStorage`。
- 随机数：`mulberry32` 种子随机，**关卡号 n 派生种子**（`seed = n * 2654435761 % 2^32` 再混淆一次），保证任何人、任何设备第 n 关布局完全一致。
- 调试参数：`?level=123` 直达指定关；`?debug=1` 在控制台输出求解器状态，并在画面上高亮当前可出场车辆。

## 2. 核心玩法（P0）

### 2.1 棋盘与车辆

- 棋盘为 cols×rows 网格（尺寸随关卡变化，见 §4.1）。
- 格子类型：空地 / 车辆占格 / 障碍（石墩锥桶，不可移动不可穿过）/ 锁定车位（P1，见 §6）。
- 车辆：长度 2（小汽车）或长度 3（巴士），宽 1 格；横或竖摆放；**车头方向 = 其唯一移动方向**，车身上画白色箭头指示。
- 载客量：小汽车 4 人，巴士 8 人。
- 车辆 4~6 种颜色循环分配（纯视觉，不影响规则）。

### 2.2 操作规则（滑动语义）

点击任意车辆：

1. 车辆沿箭头方向**逐格前进**：前方格为空则继续前进；前方为车辆/障碍/边界则停在阻挡物前一格，播放碰撞抖动 + 音效。
2. 若从当前位置到棋盘边缘整条路径畅通 → 车辆**冲出停车场**（沿方向驶出画面的动画），视为接走乘客离场。
3. 一次点击计一步（moves+1），无论滑动了多少格。

「可出场」判定：车头前方直到出板边界的所有格子均无占用（车辆/障碍均算占用）。

### 2.3 乘客、进度与胜负

- **排队人数**（顶部显示）= 场上剩余车辆载客量之和（初始 = 全部车辆之和），每出场一辆减去其载客量；顶部画一排简化小人队列（装饰性，随数字减少）。
- **进度条**（左侧竖向）= 已出场车辆数 / 总车辆数，显示百分比。
- **胜利**：所有车辆出场 → 结算弹窗（星级 + 金币 + 下一关按钮）。
- **星级**：设 par = 生成器记录的参考步数（§4.2）。moves ≤ par 且未用道具 → 3★；moves ≤ par×1.5 或用道具 ≤1 个 → 2★；其余 1★。
- **死锁检测**：当场上所有车辆既不能出场也不能滑动（每辆车前进 0 格）时，弹「堵死啦」提示层，提供「使用道具 / 重开本关」两个入口。
- 无失败惩罚，顶部随时可点重开按钮重开本关（重开不返还已消耗道具）。

### 2.4 动效音效（P2，但建议做，手感差距很大）

- 音效：引擎起步、碰撞闷响、出场欢快音、金币叮、按钮点击（WebAudio 振荡器合成即可）。
- 动效：出场驶离补间 + 车尾尘土粒子；碰撞水平抖动 150ms；排队小人减少时弹跳；出车时排队数字滚动减少。
- **连击**：5 秒内连续出场 ≥3 辆，屏幕飘「连击 ×N」并给额外金币（N≥3 每辆 +2 金币）。

## 3. 道具系统（P1，无广告无内购，金币经济）

初始资产：金币 200；提示×3、撤销×3、翻转×2、消除×1、刷新×1。

产出：每关胜利金币 = 20 + 星级×10 + 连击奖励；本关**首次**拿到 3★ 额外 +20。

商店：胜利结算弹窗与堵死弹窗内可直接金币购买道具：提示 30 / 撤销 20 / 翻转 40 / 消除 80 / 刷新 60。

| 道具 | 效果 | 交互方式 |
|---|---|---|
| 提示 | 调用求解器，高亮一辆当前可出场的车（脉冲光圈 3 秒） | 点按钮即生效 |
| 撤销 | 回退最近一次移动（本关内完整历史） | 点按钮即生效，可连点 |
| 翻转 | 选一辆车，车头方向旋转 180° | 进入选择模式：目标车高亮呼吸，点击生效，点按钮/空白处取消 |
| 消除 | 直接移除任意一辆车（视作出场接客，但**不给**连击金币） | 同上，选择模式 |
| 刷新 | 剩余车辆整体重新布置为一个新的**有解**布局（用 §4.2 生成器对剩余车辆重排，重试仍保解） | 点按钮 → 确认弹窗 → 生效 |

细节规则：

- 选择型道具未选中目标前再点一次按钮或点棋盘空白 = 取消，不消耗。
- 道具数量为 0 时按钮置灰，点击弹出金币购买入口；金币不足提示「金币不足」toast。
- 撤销只回退车辆移动，不恢复已消耗的道具；消除/刷新操作本身不可被撤销。

## 4. 无限关卡生成（P0，核心难点，重点实现）

### 4.1 难度参数曲线

关卡 n 从 1 开始，全部参数由公式给出并 clamp：

| 参数 | 公式 | 上限 |
|---|---|---|
| cols | 6 + floor(n/10) | 8 |
| rows | 7 + floor(n/8) | 10 |
| 目标车辆数 | 8 + floor(n×1.2) | 占格率 ≤ 55% 时取最大 |
| 巴士占比 | 0.1 + n×0.005 | 0.3 |
| 障碍数 | n<5 ? 0 : floor((n-3)/4) | 6 |
| 锁定车位 | n≥10 ? floor(n/10) | 4 |

每 10 关（n%10==0）为**困难关**：目标车辆数 +15%，通关金币 ×2，关卡标题加「困难」角标。

### 4.2 逆推生成算法（保证有解）

思路：先随机决定「出场顺序」，再按从后往前的顺序放置车辆，使每辆车放置时其出场路径不与已在场的车冲突——这样按该顺序逐辆点击必然全部可出。

1. `seed = derive(n)`，初始化 RNG；按 §4.1 算出网格与参数。
2. 放置障碍与锁定格：随机撒点，但**不出现在最外圈一行/一列**（保证出场通道存在），互不相邻。
3. 生成 N 辆车的属性（长度/朝向/出场方向），出场方向四边均可，随机分配。
4. 按「第 N 辆最先放、第 1 辆最后放」的顺序放置：放置第 k 辆时，从其车身占格到出场边的整条直线路径**不得穿过**任何已放置车辆与障碍；车身占格在合法范围内随机（允许贴边）。单辆重试超 50 次则整体重摇。
5. 记录顺序长度为 par。
6. 校验：用 §4.3 求解器求解初始局面，要求 `solvable == true` 且求解步数 ≤ par×2（避免生成实际更绕的假解）；不满足则重生成，最多 20 次，仍失败则降低车辆密度 10% 再试（保底必出关）。
7. 输出关卡数据：`{ n, seed, cols, rows, obstacles[], locks[], vehicles:[{id,len,orient,x,y,dir}], par }`。

### 4.3 求解器（生成校验 / 提示道具 / 死锁检测 三处共用）

- 状态：所有车辆位置集合（序列化为字符串去重）。
- 转移：当前所有「可出场」车辆（§2.2 判定），移除后进入下一状态。
- 算法：BFS 或迭代加深 DFS，找到任一全出解即返回（只需可解性 + 首步提示，不需最优解）。
- 节点上限 5 万，超限返回 `unknown`（生成器遇 unknown 视为失败重摇；运行时用于提示则退化为「高亮任一当前可出场的车」）。
- 死锁判定：不存在可出场车辆 **且** 不存在可滑动车辆。

## 5. UI 结构（对照参考截图布局）

- 顶部栏：暂停/重开圆钮（左）｜「第 N 关」胶囊（中）｜排队人数牌（数字 + 小人图标）。
- 左侧：竖向进度条 + 百分比 + 工程师小头像（Canvas 画个安全帽小人即可）。
- 中部：停车场棋盘——浅蓝地面、虚线车位框、边缘画出入口坡道涂装。
- 底部道具栏：5 个道具按钮（图标 + 剩余数量角标），右侧金币余额。
- 弹层：胜利结算、堵死提示、暂停菜单（继续/重开/音效开关/重置存档）。
- 视觉风格：卡通风、高饱和（车用红黄蓝绿粉）、圆角、粗描边阴影，参考「Parking Jam」类休闲游戏质感；不追求 3D，俯视 2.5D 感（车顶高光 + 投影）即可。

## 6. 锁定车位（P1）

- 锁定格画灰色车位 + 锁图标，开局视作障碍（不可停放不可穿过）。
- 点击锁定格 → 花费金币解锁（费用 = 20 + 关卡数），变为普通空地，本关内有效。
- 这是花钱「腾位置」的正向手段，与消除道具互补。

## 7. 存档结构

`localStorage` key：`nuonuocar_save_v1`

```json
{
  "level": 12,
  "coins": 340,
  "props": { "hint": 3, "undo": 3, "flip": 2, "remove": 1, "shuffle": 1 },

  "settings": { "sound": true }

```

通关即 `level = max(level, n+1)`；主界面（若有）从 `level` 继续；提供「重置存档」入口（二级确认）。
