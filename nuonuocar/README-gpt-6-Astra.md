# 挪挪车 · PARK & GO

根据用户提供的挪车接客视频实现的手机 H5 游戏。入口为 `index-gpt-6-Astra.html`，所有新增文件带 `gpt-6-Astra` 标识，每个源码文件不超过 1000 行。无构建、无需安装依赖、没有第三方资源请求。

## 开始游戏

在仓库根目录启动静态服务：

```sh
python3 -m http.server 8876 --bind 0.0.0.0
```

电脑访问 `http://localhost:8876/nuonuocar/index-gpt-6-Astra.html`。手机和电脑连接同一 Wi-Fi，将 localhost 替换成电脑的局域网 IP。也可将整个目录部署到任意静态托管；直接打开 HTML 可玩，但浏览器对本地文件的存档支持可能不同。

## 玩法

点击车辆，沿箭头方向前进。阻挡车辆会停在前方空位；道路畅通后驶上道路、转向并停入候车位。停稳后开门，队首同色乘客逐个走到车门上车，座位数逐人增加，满员关门后驶离。未等到同色乘客的车辆会持续停在车位上。车辆有加高驾驶舱、斜面玻璃、车身侧面、轮胎和投影，停车场也绘制了对应车位线。送走全部乘客即可进入下一关。

四个免费候车位；本关可用金币增加两个。五种道具：提示、刷新、消除、排序、翻转。选车道具点空白、取消按钮或再次点道具均可取消，不扣数量。免费撤销不返还道具。金币通过通关获得，同关只领取首次奖励和星级提升差额，无广告或付费接口。

关卡区和道具栏采用紧凑布局。390×844 下，停车场画布由约 221px 增加到 387px，并加大棋盘投影。接客时可继续点其他车辆出场：每辆车立即预留一个空车位，驶入、上客和驶离分别运行。乘客队列保持顺序，只给停稳的车上客。四个车位全部被预留时，额外车辆留在停车场；待车位释放后即可继续。调度尚未结束时不弹堵死提示。撤销、重排等会改动已有状态的操作等待当前调度结束后使用。

暂停菜单支持重开、音效、说明及二次确认重置存档。游戏会自动保存当前棋盘、队列、金币、道具和关卡，撤销历史仅在本次页面内有效。

## 无限生成的实现

关卡编号派生确定性随机种子，棋盘由 7×7 逐步增长到 9×9，车辆目标数量上限 27，六种颜色逐步开放，每十关奖励翻倍。实际车辆数量由可合法放置的数量决定。界面持续开放下一关，没有预置关卡表。

构造时，每辆新车的出口不被已放置车辆阻挡，倒序移除即得到一条解。乘客队列沿该解构造，因此按参考顺序无需道具即可完成接客。移除车辆只会开放更多道路，因此几何验证采用贪心拓扑剥离，无需指数级搜索。每辆车可出场即移除，不能继续剥离则存在依赖环。

翻转和错误发车可能造成堵塞。刷新保留剩余容量和已送达人数，重建可解车阵和相应队列，同时先安排现有候车位乘客。排序优先取出一辆候车车所需的乘客；消除直接送走选中车辆对应乘客。

`?level=123` 可指定起始关卡，进入后移除该参数，刷新继续当前局面。`?debug=1` 高亮可出场车辆并开放 `window.parkingDebug`，便于验证引擎、坐标命中和存档。普通模式不开放该调试接口。
