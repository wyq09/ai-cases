# FIERY DRAGON · 火龙珠水果机

经典街机「火龙珠」跑马灯水果机的 1:1 H5 复刻。单文件 `index.html`，零依赖、零外部资源 —— 全部图形为手绘 SVG，全部音效为 WebAudio 程序化合成。

## 玩法

- **投币**：底部「投币 +1」/「上分 +100」增加 CREDIT（支持自动投币）
- **押注**：8 个门子 BAR(100) / 77(40) / 星(30) / 西瓜(20) / 铃铛(20) / 柠檬(15) / 橙(10) / 苹果(5)，点绿色钮押分，长按连押，`ALL+1` 全门押注
- **开灯**：`GO` 后跑马灯加速→全速→缓降悬念停止；押中停下格子的符号即赢「押注 × 倍率」
- **特殊格**：`x3` 格倍率 ×3；`LUCK` 送免费一局（可连锁）；中 `BAR` 天女散花全屏庆典；`BAR×100` 独吞 JP 彩金池（每次押注自动累积）触发 JACKPOT
- **比倍**：中奖后进入猜大小 —— `←→` 调整比倍额，`1-6` 猜小 / `8-13` 猜大开 13 格数字轮盘，猜对翻倍可连续比倍，7 通杀；`GO/收分` 落袋为安
- 进度自动存档（localStorage），顶栏 `≡` 有设置与演示辅助，`i` 有玩法说明

## 技术要点

- **渲染**：DOM/CSS 拟物布局（750×1610 设计坐标系，`transform: scale` 多端适配）+ Canvas2D 粒子层（金币喷泉/雨、彩带、天女散花瓣、冲击波、大字冲屏；对象池 + 预渲染贴图，无 shadowBlur）
- **跑灯**：rAF 预计算步进曲线（全速 28ms/格 → 缓降 340ms/格悬念），tick 音调随速度变化
- **LED**：程序生成七段数码管 SVG（前导零暗显、数字滚动动画）
- **声音**：真实采样（[Mixkit](https://mixkit.co/free-sound-effects/slot-machine/) 免费授权音效 + 欢快 BGM 循环，`assets/` 本地托管）+ WebAudio 合成兜底（tick 等高频音），主增益 + 程序生成 IR 混响，iOS 手势解锁
- **服务端适配层**：`LocalServer.spin()/guess()` 两个 async 接口隔离全部开奖逻辑，内置街机式概率控奖（分段衰减 + 动态冷格吃分）。接入真服务端时仅需替换为 HTTP/WebSocket 请求，前端状态机零改动

## 开发

```bash
./build.sh   # src/shell.html + src/{art,audio,fx,game}.js -> index.html
```

调试参数：`?reset=1` 清存档 · `?cell=N` 强制下局停格 · `?rig=win|lose` 控奖倾向 · `?muted=1` 静音 · `?auto=1` 自动投币
