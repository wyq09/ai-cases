# bloub

一个纯 SVG 形变动画的可定制头像玩具:黑色小圆球在 14 种状态间丝滑 morph,可换形状、表情、颜色,编排动画序列,并导出成 PNG / GIF / WebM。

**零依赖、零构建** —— 原生 ES Modules + 手写渲染引擎,克隆即用。

## 特性

- **8 种形状** × **16 种表情** × **12 种颜色**,任意组合
- **14 种状态动画**:静止、思考、眨眼、睁大眼睛、警示、通知、感叹号、休眠、蛋形、播放、轨道、爆散、彗星、漩涡
- **丝滑 morph**:所有轮廓统一为采样点集,形状/表情/状态切换全程逐点插值,60fps
- **动画序列编辑器**:把状态动画串成轨道,循环播放,支持多序列管理(localStorage)
- **导出**:PNG 静图、GIF 动图(自研 GIF89a + LZW 编码器,支持透明)、WebM 视频、剪贴板复制
- **三语界面**:简体中文 / English / Français,自动检测浏览器语言
- 响应式布局,尊重 `prefers-reduced-motion`

## 运行

任意静态服务器指向本目录即可:

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 结构

```
index.html              入口
assets/css/style.css    全站样式与过渡曲线
assets/js/core/         几何采样 / 缓动 / 渲染引擎 / GIF 编码器
assets/js/data/         形状、表情、颜色、状态动画定义
assets/js/*.js          应用装配、导出、i18n、本地存储
```

## 技术要点

- 形状与眼睛统一表示为固定点数的闭合点集,morph 即逐点插值,经 Catmull-Rom 转三次贝塞尔保证曲线一阶连续
- 状态动画是参数轨道(缩放/鼓包/尖刺/扭曲/眼睛),叠加在任意形状与表情之上,因此「形状 × 表情 × 动画」自由组合
- 切换形状、表情、状态动画时,从当前帧向目标缓动过渡,永无跳变
- 面板与对话框过渡使用 `cubic-bezier(.22, 1, .36, 1)` 签名曲线
