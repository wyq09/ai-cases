# 天之第三极 · 珠穆朗玛峰海拔带纪行（Everest Vertical Atlas）

一篇配有 **7 幅全幅版画风格插图** 与 **3 组交互式科学图表** 的长篇中文地理随笔网页，自 1,500 米湿润的印度洋季风河谷逐级攀升至 8,848.86 米对流层之巅，系统解读珠穆朗玛峰的地质成因、南北坡垂直带谱不对称性与六大海拔带的气候、生态、人体生理和人类足迹。

- **在线预览**：<https://case.youyongai.com/everest-essay/>（亦支持本地双击 `index.html` 通过 `file://` 离线阅读）
- **单文件交付**：`build.py` 将 `src/*` 与压缩后的 7 幅 WebP 版画插图打包为单个约 **1.77 MB** 的 `index.html`，零外部网络请求。

## 阅读与交互体验

1. **七幅统一画风的版画插图 + 全屏原图鉴赏（Lightbox）**
   - 封面全景 + 六大海拔带（1,500–3,000 m 暖湿阔叶林与杜鹃峡谷、3,000–4,000 m 亚高山冷杉与糙皮桦林线、4,000–5,000 m 高寒草甸与牦牛牧场、5,000–6,000 m 珠峰大本营与昆布冰瀑、6,000–8,000 m 寂静谷与洛子冰壁、8,000–8,848.86 m 死亡地带与顶峰刃脊）。
   - 点击任意图版可弹出全屏原图鉴赏窗口，支持左右切换与 `Esc` / 方向键操控。
2. **随滚动实时演算的垂直海拔仪表（Live Altimeter）**
   - 顶部状态栏与桌面右侧固定海拔导航栏随阅读进度连续插值当前海拔（`1,500 m → 8,848.86 m`），实时计算并显示大气压（hPa）、相对有效含氧（%）与纯水沸点（°C）。
   - 步入海拔 8,000 米以上的“死亡地带”章节时，页面自动切入全幅深邃高空暗境色阶与高对比度霜白排版。
3. **交互式南北坡垂直海拔带剖面图**
   - 原生 SVG 交互纵剖图，支持切换「南北坡全景对比 / 聚焦南坡（尼泊尔湿润季风）/ 聚焦北坡（中国西藏高原雨影）」，点击任意海拔带色块、营地圆点或右侧编号即可查看气压、含氧、沸点、植被动物与南北坡差异，并一键跳转正文。
4. **地质板块碰撞剖面图 & 高海拔物理与生理实验室**
   - 直观呈现印度板块俯冲抬升古特提斯海奥陶纪灰岩至 8,848 米的造山过程。
   - 拖动 `0 m – 8,848.86 m` 标尺或点击典型地标预设（海平面 / 拉萨 / 勃朗峰 / 珠峰大本营 / 乞力马扎罗 / 南坳 / 珠峰顶），实时联动大气压衰减曲线、吸入氧分压 $P_iO_2$、纯水沸点、紫外线倍数与医学高反分级。

## 技术要点

- **零外部依赖单文件架构**：纯原生 HTML / CSS / ES 模块组织源码（`src/data.js`、`src/diagrams.js`、`src/app.js`、`src/style.css`、`src/template.html`），经 `build.py` 使用 `cwebp` 将 7 幅高清插图压缩为 WebP Data URI 并完成 `node --check` 语法与零外链校验。
- **高海拔物理模型**：基于标准大气压公式并叠加喜马拉雅副热带夏季暖柱修正（8,848.86 m 实测夏季气压 ~337 hPa、有效含氧 ~33.3%），结合克劳修斯-克拉佩龙沸点近似与人体吸入氧分压公式。
- **响应式多端排版**：桌面 1440px 与移动端 390px 自适应，滑出式目录抽屉、无横向溢出、支持 `prefers-reduced-motion`。

## 测试与验收情况

- **Node 逻辑与打包完整性回归（`node everest-essay/test/run.mjs`）**：**9 / 9 项全绿**（覆盖海平面基准、8,848.86 m 峰顶物理指标、5,364 m 大本营半压验证、全海拔单调性、六大海拔带无缝衔接、临床生理分级、单文件 7 图内联与零外部 URL 断言）。
- **ego-browser 多端 UI 与视觉回归**：**15 / 15 项全绿**，桌面端（1440×900）与移动端（390×844）零横向溢出、7 幅图版全部加载、南北坡剖面切换/选带、图版 Lightbox、死亡地带深色章节切换、海拔实验室预设与目录抽屉全部通过，实拍验收图留档于 [`shots/`](./shots/)。
