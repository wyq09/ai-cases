# 僵尸防线 · 孤哨重制

「僵尸防线 · 至尊版」H5 复刻 —— 玩法与数值 1:1（局内 roguelike 三选一 + 局外养成/宝石抽卡/模拟充值），视觉全面重做为「末日孤哨」军事风，手机全屏自适应，单文件 120KB 零外部资源离线可玩。

**在线游玩**：<https://case.youyongai.com/zombie-defense/>

## 玩法

- 拖动屏幕左右移动哨兵，自动索敌射击从天而降的僵尸潮，守住防线沙袋墙
- 击杀得经验，升级三选一学技能（火力/多弹道/穿透/爆破/冰冻/燃烧/无人战机/制导激光/雷电链/弹幕风暴/处决令…一局最多 4 系）
- 每 5 波 Boss 来袭：远程弹+高额血量，击破必掉 20 钻并回复防线
- 金币 → 军备研究所买 4 项永久属性（各 20 级）；钻石 → 至尊宝箱抽 6 种宝石（传说/绝世/至尊三品质全局叠加生效）
- 充值中心为纯单机模拟（¥6/¥30/¥98，首购双倍），VIP 等级提升金币收益，0 元真实扣费
- ×1/×2/×3 倍速、暂停结算不白打、`?reset=1` 清档、存档自动保存

## 技术要点

- **契约先行并行开发**：`src/contract.md` 锁死全部数值与模块接口，主线写逻辑/状态机/UI，两个子代理并行产出 canvas 美术与 WebAudio 音效
- **全程序化视觉**：多层夜空/月亮/双层废墟剪影/雾带/战壕离屏预渲染，四型僵尸差异剪影+多通道步态动画，发光全部预渲染 sprite 或 radial-gradient+lighter（零 shadowBlur）
- **全程序化音效**：WebAudio 合成 22 种音效（枪声/暴击/雷链/宝石揭示/BGM 双场景暗黑垫乐），文档级 pointerdown 解锁，BGM 交叉淡切
- **DOM UI + Canvas 战场**：军琥珀/骨白/血红「末日孤哨」视觉系统，HUD/技能坞/波次横幅/三选一卡片/结算战报表全 DOM（safe-area 适配），内联 SVG 图标零 emoji
- **rAF + setInterval 双驱动定步长**：后台不冻结、倍速稳定 ×3；账目不变式（结算金币=runCoins×(1+加成)）实测对账
- 手机 390×844 / 横屏 844×390 / 桌面 1440×900 letterbox 三视口零溢出，90 秒 ×3 速浸泡零报错
