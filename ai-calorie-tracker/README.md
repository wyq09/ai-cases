# ai-calorie-tracker · 食光 AI

AI 食物识别卡路里记录应用的移动端 H5 高保真交互复刻。参考三屏设计稿 1:1 还原（引导页 / 仪表盘 / 搜索页），并补齐扫描识别、食谱详情、收藏、设置等页面，形成完整可玩的应用闭环。零依赖、纯静态。

## 预览

桌面浏览器打开 `index.html`（居中手机壳展示，灵动岛 + 393×852 视口；≤520px 视口自动全屏）。

```bash
# 可选：本地起个静态服务
python3 -m http.server 8000
# 访问 http://localhost:8000/ai-calorie-tracker/
```

## 页面与功能

**引导页** — 三屏全屏食物摄影轮播（拖拽手势 / 圆点直达 / 跳过），白色卡路里标注气泡浮动动画，「开始使用」进入仪表盘。

**仪表盘（首页）** — 12 段弧形卡路里仪表（依次点亮 + 数字 count-up，总量 / 目标 / 占比实时联动）、今日日期、「+」添加条（拍照识别 / 搜索食谱 / 快速添加常见食物）、餐次卡片（热量、占目标百分比、蛋白质 / 碳水 / 脂肪）、编辑记录（份量步进等比换算营养值、删除）、本周概览弹层、通知中心。

**扫描识别（中央橙色按钮）** — 深色取景框 + 扫描线动画，快门触发模拟 AI 识别流程（闪光、扫描加速、「检测食物 → 匹配数据库 → 估算份量」状态流转），识别结果弹层：置信度、预计热量、三大营养素、份量步进实时换算，「添加到今日饮食」回写仪表盘。

**搜索 / 食谱** — 实时搜索过滤、emoji 分类筛选（素食 / 高蛋白 / 零食 / 早餐 / 低卡）、热门食谱横滑大卡（难度条、收藏星标）、查看全部列表形态；食谱详情页：头图、meta 芯片、营养三格、食材清单、编号做法、选择餐次加入今日饮食。

**收藏** — 已收藏食谱列表，取消收藏收拢退场动画，空状态引导。

**设置** — 每日目标热量滑杆（仪表盘同步更新）、记录提醒开关、关于、清除本地数据（恢复初始演示态）。

状态（饮食记录 / 目标 / 收藏 / 开关）持久化于 `localStorage`，URL 追加 `?reset=1` 可重置演示数据。

## 技术说明

- 原生 HTML / CSS / JavaScript（ES Modules），无框架、无构建
- Hash 路由 + 动态 import 页面模块，页面模块只依赖 `store.js`（状态订阅）/ `ui.js`（el、SVG 图标、底部弹层、Toast）/ `data.js`（食谱与识别候选数据）
- 图标为内联 SVG 线性图标集；字体本地内嵌 Plus Jakarta Sans（数字 / 西文），中文回退系统字体

## 声明

本项目为前端交互复刻演示，识别流程为模拟实现，数据仅保存在浏览器本地。图片素材来自公开食谱站点，仅作演示用途。
