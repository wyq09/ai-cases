# 高级感配色 · 色卡生成器

复刻一组「世界上最高级的配色」小红书风格卡片（7 组主色辅色 + 暗夜极光封面），并提供同款色卡生成器：填入自己的主辅色即可实时预览、一键下载 1080×1440 高清 PNG。

纯静态实现，无构建依赖，直接打开 `index.html` 或用任意静态服务器托管即可。

## 特性

- **灵感图鉴**：8 张海报 1:1 复刻（玻璃光泽、底部波浪、山峰剪影、丝绸缎带、珠光圆球、颗粒质感），桌面网格 / 手机横滑浏览
- **色卡生成器**：自定义标题、页码、主辅色（名称 / 色值 / 描述）与底部文案，Canvas 实时渲染
- **6 种背景预设**：暖调奶油、玫瑰拂晓、暮蓝烟紫、暖调竹影、雾紫暮光、暗夜极光
- **随机灵感**：从 28 色莫兰迪色库中按明度对比自动配对，附带诗意的中文色名与释义
- **下载保存**：1080×1440（3:4）高清 PNG，尺寸适配小红书图文；iPhone 提供长按保存弹窗
- **一键套用**：图鉴中任意配色可一键载入生成器继续创作
- **复制文案**：生成可直接粘贴到小红书的配色文案

## 技术要点

- 海报复刻采用固定 540×720 设计稿 + `transform: scale()` 自适应，任意屏幕下构图不变形
- 生成器预览与下载产物出自同一个 Canvas 渲染函数（1080×1440），所见即所得
- 光泽与虚化全部用渐变 / `backdrop-filter` / 径向渐变模拟实现，不依赖 WebGL 与外部图片
- 衬线字体使用 Noto Serif SC（Google Fonts），并回退到系统宋体
