# bull-flight · 小飞牛炒股大冒险

"炒股版 Flappy Bird"——小飞牛在 K 线图里飞行：点屏幕冲高（做多力量），撞上"买"按钮按交易风格买入、撞上"卖"按钮全部平仓，躲开半透明挡板；触及 ±10% 涨跌停或撞管即强制平仓，收盘弹出战报。

单文件 H5，零外部资源，离线可玩。

## 玩法

- 点击屏幕任意处：小牛向上冲（价格随之被推高）
- 撞到红色"买"按钮：按当前交易风格买入（半仓滚动：剩余现金的 50%，可连续加仓）
- 撞到绿色"卖"按钮：全部平仓，浮盈落袋、浮亏扣除
- 躲避挡板（半透明管道）；触及涨停/跌停边界或撞上挡板即本局结束，自动强平结算
- 开局可借款加仓（最多总资产 50%，收盘自动还贷，还不上即破产）
- 收盘战报：收益率、净收益、买卖次数、最大回撤、收益走势图与称号评定；本金跨局滚动

## 技术要点

- **价格与账目同源**：牛的 y 即当前股价，K 线按时间聚合 OHLC（帧率无关）；每 tick 断言账目恒等式 `净值 ≡ 本金 + 贷款 + 已实现盈亏 + 浮盈`
- **结算统计**：逐 tick 净资产曲线、最大回撤、按收益率+回撤分档的称号（"账户医学奇迹"= 盈利且回撤 ≥5%）
- **全程序化资产**：小牛两帧扇翅 SVG、14 枚图标、装饰二维码、9 种 WebAudio 音效 + lo-fi BGM
- **游戏内配置面板**：小牛立绘上传替换、重力/冲力/噪声/滚动速度/管道空隙/税费率调节、配置导出导入
- **Canvas 粒子**：金币/羽毛/浮字对象池，无 shadowBlur
- **自适应**：390 竖屏 / 横屏 / 桌面；`?auto=1` AI 自动演示，`?reset=1` 清档，`?muted=1` 静音
