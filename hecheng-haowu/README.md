# 合成好物

微信小游戏《合成好物》风格的 1:1 复刻 H5。拖动两个相同商品合成升级，点击配送员生成新商品，X5 一键合成，做任务得体力，完成关卡目标领取补分与金币。纯原生 DOM + SVG + WebAudio，单页实现，无构建、无外部依赖、无任何 emoji（全部图标为手写 inline SVG 矢量）。

## 特性

- 拖拽合成：Pointer Events 手势，拖动两个相同商品合成升级，支持空格移动、误放回弹
- 配送员生成商品：消耗 1 点体力在随机空格生成 V1 商品，金框高亮引导点击
- X5 一键合成：消耗体力自动完成最多 5 次同级别合成，飞行动画 + 逐格爆发特效
- 关卡系统：从第 1 关从零开始（金币 / 补分 / 进度归零、空棋盘），每关独立商品链：1 面包 / 2 野生松茸 / 3 安睡裤 / 4 鲜榨橙汁 / 5 茶叶蛋 / 6 毛巾，之后循环生成，目标商品达成后一键领取奖励进入下一关
- 自定义配置：右缘齿轮打开配置面板，17 种商品均可上传本地图片替换图标、修改名称，立即生效并持久保存，支持单项恢复与一键全部恢复默认
- 演示体力：任务列表内置【演示】手动领取体力 +5，可重复领取
- 分数与奖励：合成得补分（本关进度条）、领奖励得金币、补分累计进存钱罐；闯关成功结算弹窗（奖杯 + 彩纸 + 补分总计）
- 任务系统：10 项「做任务得体力」任务，去补分签到完整闭环（我的补分页 → 7 日签到 → 签到成功弹窗 → 返回领取体力），其余任务为演示占位
- 我的补分页：存钱罐余额、每日签到、补分兑换区（兑换扣减补分余额）
- 合成特效：金色冲击环、蓝白气泡、星星迸溅、+补分漂浮字、商品弹出回弹、飞行拖尾
- WebAudio 实时合成音效：点击/生成/合成/金币/过关/任务六种，无音频素材文件，右缘音符按钮开关
- 农场场景背景：天空、云、白色风车、绿树、白栅栏、草地条纹与小雏菊，全部为分层 inline SVG
- 进度自动存档：体力、金币、补分、棋盘、关卡、签到与任务状态实时写入 localStorage，重开自动恢复；`?reset=1` 或规则弹窗内可重置

## 快速开始

- 直接用浏览器打开 `index.html` 即可游玩；或通过任意静态服务器访问目录。
- 手机或微信内打开体验最佳；桌面端自动居中满高显示。
- 拖动两个相同商品合成升级；体力每 30 秒回复 1 点（上限 25），也可做任务获取。

## 目录结构

```
hecheng-haowu/
├── index.html            # 游戏主体（布局 / 样式 / 全部逻辑）
└── assets/
    ├── icons.js          # 44 个 inline SVG 图标（商品 / UI / 任务 / 配送员）
    ├── scene.js          # 农场场景背景 SVG
    └── preview-*.html    # 素材自检预览页（开发用）
```

## 自动化测试钩子

供 E2E / 调试使用，不影响正常游玩：

- `window.__probe()`：读取当前关卡、体力、金币、补分、棋盘与报错状态
- `window.__cheat.give(k, n)` / `win()` / `energy(n)` / `clear()` / `drag(a, b)` / `burst(i)`
- `window.__frame(ms)`：测量段时间内的帧率统计
- `window.__errs`：运行时错误收集
