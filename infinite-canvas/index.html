素材

Cmd V直接粘贴剪贴板里的图片 / 视频文件，或复制的图片 URL

拖入把本地图片、视频文件拖到画布任意位置

双击空白处新建文字，N 放置彩色便签

连线

圆点悬停节点，从边缘圆点拖到另一个节点

双击连线删除该连线，或选中后按 Delete

视图

滚轮平移画布，Cmd+滚轮以光标为中心缩放

空格按住空格拖动，或中键拖动，或 H 抓手工具

0适应全部内容，1回到 100%

编辑

Cmd Z撤销 · Cmd Shift Z重做 · Delete删除选中

Cmd D复制一份 · Cmd A全选 · 方向键微调位置

拖框空白处拖拽框选多个节点

快捷键以 macOS 为准 · Windows 下 Cmd = Ctrl
内容自动保存在本机浏览器（IndexedDB）
