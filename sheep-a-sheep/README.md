# 羊了个羊 · 三消羊圈

经典三消 tile 层叠游戏的手机端复刻：点击无遮挡的牌飞入底部槽位，凑齐三张相同图案即消除，清空全场过关。无限关卡由种子确定性生成并经求解器验证保证可解；牌面图标、背景、音效、全部难度参数均可在游戏内配置面板自定义。单文件零外部资源，离线可玩。

[在线游玩](https://case.youyongai.com/sheep-a-sheep/)

## 玩法

- 点击场上未被压住的牌，牌飞入底部槽位（默认 7 格）；槽内凑齐 3 张同图案自动消除
- 槽位塞满且无法消除即失败；清空全场全部牌即过关，进入下一关
- 三道具：移出（槽内前 3 张放回场上顶层）、撤销（收回最后一张）、洗牌（重排场上图案）；失败还有复活机会（清空槽位）
- 难度逐关爬升：种类、牌数、层数、叠压密度、侧堆随关卡增长，每 5 关一个喘息关
- 设置面板：17 项难度参数（槽位数/种类/牌数曲线/层数/密度/侧堆/道具次数/复活/保证可解开关）、14 种牌面图标逐个上传替换、背景替换、牌面配色、音效逐条替换、配置导出导入

## 技术要点

- **可解性保证**：随机布局 + 图案分组后，用「贪心 + 预算回溯」求解器验证（同 kind 候选剪枝加速），不可解自动重摇，同关同种子可复现
- **一份求解器三用**：生成验证 / AI 演示（`?demo=1` 逐步走可解路径自动通关、失败自动换种子重试）/ 调试钩子提示
- **难度模拟器**：玩家容错模型（skill 参数混合贪心与随机选牌 + 道具简单规则）批量模拟各关通过率，据此校准难度曲线
- Canvas 全程序化渲染：半格精度层叠布局、z 序遮挡罩暗、贝塞尔飞牌、消除聚拢演出、粒子彩纸；rAF + setInterval 双驱动防后台节流冻结
- WebAudio 全合成 12 cue（马林巴五声音阶田园 BGM）+ 逐条音效上传替换
- 进度与配置双 key 持久化，`?reset=1` 清档；390 竖屏 / 横屏 / 桌面收壳自适应

## 开发

```bash
python3 build.py   # 拼接 src/*.js → index.html 单文件
```

调试参数：`?level=N` 跳关 · `?demo=1` AI 演示 · `?snap=1` 零动画 · `?muted=1` 静音 · `?reset=1` 清档；逻辑单测 `node tools/test-logic.js`（生成/求解/复现/模拟器）
