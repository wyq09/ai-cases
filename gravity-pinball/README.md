# gravity-pinball 重力弹球王

微信小游戏「重力弹球王」的 1:1 复刻：球从顶部黑色漩涡漏斗落入封闭球场，撞击带数字的彩色 bumper 让数字递减、归零爆炸得分，清空全场进入下一关，关卡无限。单文件 H5，手机浏览器直接可玩。

## 玩法

- 按住拖动瞄准（杯口→手指白色羽箭虚线 + 青环触点球），松手把全部球朝该方向成串发射（出膛沿瞄准线直线制导，指哪打哪）；球不消耗，停稳自动飞回等下一轮，「收球」可立即全收
- 每打完一轮（球全部收回），场上障碍物整体上移一格，节奏逐步收紧
- 撞目标数字 −1；消除得分 = 初始数字 ×5；菱形 ×2 倍、大白球 ×3 倍；倾斜圆角方块、描边三角为变体目标
- 点按屏幕发出冲击波把球弹开；把球送进顶部漩涡 = +15 分 +3 球；场内红圈加号拾取球 = +2 球
- 炸弹：发射串首颗球落地即爆，半径内数字 −6；沙漏：慢动作精准狙击
- 「加球」花分数买球（分不够可定时免费领）；清空全部数字球过关，目标数量/计数/移动目标随关卡无限增长，进度本地持久化

## 技术要点

- **零依赖单文件**：`build.py` 把 `src/*.js` 拼进 shell 骨架（约 150KB），程序化生成全部视觉与音效，离线可玩
- **自研 2D 物理引擎**：线段/圆形/菱形与方块 OBB 碰撞、球间弹性、弧形地板、杯口单向吞噬区、弹速下限式加力（快撞有活力、轻触可沉降）、180Hz 子步防穿透，node 可单测
- **拖动瞄准发射**：杯口→手指羽箭虚线、下向锥角钳制、拖距=力度、杯口旁实时待发球数倒数；出膛 0.26s 免重力直线制导（碰撞即交还正常物理），指哪打哪
- **回合升格**：球全部收回后停顿半拍，全场障碍物带缓动整体上移一格
- **视觉还原**：糖果光泽目标球（球体渐变+彩色光晕+高光，浅底深字/深底白字）、四旋臂星系漩涡、层叠山丘+斜向天光、玻璃穹顶道具钮、接地符号墙脚
- **无限关卡**：mulberry32 种子驱动的布局生成器（圆/斜方/菱形/三角/大白球/加号拾取球），数量、计数、移动目标随关卡缩放，同关可复现
- **性能**：背景/墙线/漩涡/目标全离屏预渲染，粒子对象池 + `lighter` 叠色，DPR≤2，rAF + 看门狗双驱动
- **WebAudio 程序化音效**：碰撞随强度变调、消除/吞噬/炸弹/过关全套合成音，支持自定义音频替换
- **开放配置**：游戏内设置面板（重力/发射间隔/弹性/音量/自动收球）、炸弹与沙漏图标上传替换、配置导出导入

## 开发

```
python3 build.py        # src/ → index.html
```

调试参数：`?reset=1` 清档 · `?level=N` 跳关 · `?balls=N` 设球数 · `?muted=1` 静音；测试钩子 `window.__gp`。
