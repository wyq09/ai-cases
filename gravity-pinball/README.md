# gravity-pinball 重力弹球王

微信小游戏「重力弹球王」的 1:1 复刻：球从顶部黑色漩涡漏斗落入封闭球场，撞击带数字的彩色 bumper 让数字递减、归零爆炸得分，清空全场进入下一关，关卡无限。单文件 H5，手机浏览器直接可玩。

## 玩法

- 球自动从顶部漩涡杯口落入；「收球」把场上静止的球收回球数，「加球」花分数买球（分不够可定时免费领）
- 撞 bumper 数字 −1；消除得分 = 初始数字 ×5；菱形 ×2 倍、大白球 ×3 倍
- 点按屏幕发出冲击波把球弹开；把球点进顶部漩涡 = +15 分并回收 +3 球
- 炸弹：下一颗球落地即爆，半径内 bumper 数字 −6；沙漏：7 秒慢动作精准狙击
- 清空全部数字球过关， bumper 数量/计数/移动 bumper 随关卡无限增长，进度本地持久化

## 技术要点

- **零依赖单文件**：`build.py` 把 `src/*.js` 拼进 shell 骨架（约 100KB），程序化生成全部视觉与音效，离线可玩
- **自研 2D 物理引擎**：线段/圆形/菱形 OBB 碰撞、球间弹性、弧形地板、杯口单向吞噬区、180Hz 子步防穿透，node 可单测
- **无限关卡**：mulberry32 种子驱动的 bumper 布局生成器，数量、计数、移动 bumper 随关卡缩放，同关可复现
- **性能**：背景/墙线/漩涡/bumper 全离屏预渲染，粒子对象池 + `lighter` 叠色，DPR≤2，rAF + 看门狗双驱动
- **WebAudio 程序化音效**：碰撞随强度变调、消除/吞噬/炸弹/过关全套合成音，支持自定义音频替换
- **开放配置**：游戏内设置面板（重力/掉球间隔/弹性/音量/自动收球）、炸弹与沙漏图标上传替换、配置导出导入

## 开发

```
python3 build.py        # src/ → index.html
```

调试参数：`?reset=1` 清档 · `?level=N` 跳关 · `?balls=N` 设球数 · `?muted=1` 静音；测试钩子 `window.__gp`。
