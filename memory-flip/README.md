# memory-flip · 翻牌赢好礼

经典营销活动「记忆翻牌」H5 复刻：限时翻牌配对，连击翻倍计分，全部配对成功即可领取好礼。单文件、零外部资源、离线可玩，[在线游玩](https://case.youyongai.com/memory-flip/)。

## 玩法

- 点选两张卡牌配对：相同则保持翻开并收集好礼，不同则盖回
- 开局有短暂记忆时间，亮出全部卡面供记忆
- 连续配对触发连击，奖励分数最高翻 4 倍
- 限时倒计时内全部配对成功即挑战成功，剩余时间折算奖励分
- 按星级结算（看翻牌准确率），一键领取虚拟券码，可复制分享战绩
- 三档难度：轻松 4×3 / 标准 4×4 / 挑战 5×4；各难度独立纪录最佳成绩
- 游戏内设置面板：自定义卡面图片、替换音效、调整玩法参数、配置导出导入
- 成绩与配置本地保存，刷新不丢

## 技术要点

- **单文件交付**：`src/` 模块（logic/art/audio/fx/config-panel/game）经 `build.py` 内联拼接
- **零外部资源**：卡面全部程序化 SVG，音效全部 WebAudio 合成（含五声音阶国风 BGM）
- **Canvas 特效**：铜钱飞行、纸屑彩带、连击大字，对象池 + 离屏预渲染，无 shadowBlur
- **3D 翻牌**：CSS `preserve-3d` + `backface-visibility`，配对/失配分支状态机
- **可配置**：图标/音效上传替换（canvas 压缩 dataURL）、玩法参数热生效、work 副本 onChange 快照

## 开发

```
python3 build.py        # 生成 index.html
```

调试参数：`?reset=1` 清档 · `?auto=1` AI 自动演示 · `?grid=5x4` 难度 · `?time=60` 限时秒 · `?peek=0` 关预览 · `?muted=1` 静音
