# 鼠族跑酷 · MOUSE RUSH

横版 2D 无限关卡跑酷 H5。主角是一只戴橙红围巾、背奶酪背包的灰色小老鼠，
在厨房 / 仓库 / 雨林 / 熔岩 / 冰原 / 虚空 六大场景之间无限跑酷。
手机竖屏、横屏双适配，**支持手动切换到横屏模式**。
竖屏前方只有 **1 秒**预警视野，横屏是 **3 秒**，所以竖屏菜单会主动给「切到横屏」引导。

## 玩法

- **移动**：桌面 `←/→` 或 `A/D`；移动端左半屏**动态虚拟摇杆**（手指按下处即原点）。
- **跳跃**：`空格` / `W` / `↑`（长按跳更高）；`Shift` / `J` **冲刺**（耗体力，冷却 0.55s）；
  `S` / `↓` **滑铲**（地面）或**跳劈**（空中）；`P`/`Esc` 暂停，`R` 重开本关，`M` 必杀。
- **核心手感**：coyote time（0.10s 离地宽限）、跳跃缓冲（0.12s）、可变跳跃高度、
  冲刺带残影与火焰尾迹、滑铲压低身形过矮道、踩敌弹起、极限落地硬直反馈。
- **无限关卡**：关卡程序化生成，同种子完全可复现；每 5 关切换一个场景，26 关后循环，
  难度系数随关卡线性上升（敌人速度/密度/机关密度/道具稀有度）。
- **每关 3 条命**，死亡回到本关检查点；命尽 Game Over，通关奖励 1 条命。
- **检查点**：每段开头一个，死亡后从最近检查点复活。

## 六套积分系统（同时在 HUD 可见）

| 系统 | 说明 |
|---|---|
| 主积分 | 距离分 + 拾取分 + 风格分 + 击杀分 + 过关奖励 |
| 金币 | 经济货币，拾取获得 |
| 奶酪 | 特殊收集物，决定关卡星级 |
| 风格分 | 靠动作累积，等级 D→C→B→A→S→SS，随时间衰减、可降级 |
| 连击 | 连续拾取/击杀不断链，倍率最高 ×4 |
| 能量 | 0-100 充能，满槽可放必杀「鼠王冲刺」清屏 |

**风格动作**（共 8 种，加分各不相同）：冲刺 +50、跳劈 +80、滑铲 +40、二段跳 +30、
踩敌 +120、极限落地 +60、擦弹 +20、空中连击 +10/段（上限 +60/跳）。

## 技术要点

- **单文件零外部资源**：`build.py` 把 `src/*` 拼成单文件 `index.html`；
  美术全为程序化 Canvas2D 预渲染精灵（主角小老鼠为实时程序化绘制，含 4 腿步态 /
  耳朵围巾飘动 / 9 种姿态），音效 27 个 cue + 5 轨 BGM 全 WebAudio 实时合成，
  特效全为 Canvas 粒子池。
- **打击感**：hitstop 冻结帧（受击 90ms / 击杀 55ms / 落地 25-45ms）、trauma² 震屏、
  受击白闪、伤害数字、连击弹窗、死亡慢动作 0.35x、必杀慢动作 0.5x、
  冲击缩放（camera zoom punch）、高速速度线、低命红晕、`navigator.vibrate`。
- **性能**：粒子对象池（硬上限 520，低画质 260）、离屏精灵预渲染、
  渐变发光（禁 `shadowBlur`，用径向渐变 + `lighter`）、DPR≤2、固定步长 60Hz 物理 + 累加器。
- **镜头跟随（硬约束）**：角色相对视口的位置被**锁在 35%~55% 区间**（目标 45%），
  竖屏 / 横屏 / 桌面在任何速度下角色都不出画；出生点随视口宽度自适应，
  起跑瞬间就落在画面 ~42% 处，不会贴着左边缘。
  > 修过一处真 bug：相机变换里 `translate` 与 `scale` 顺序写反，Canvas 合成规则是
  > `translate` 后 `scale` 得到 `s·p + t`（平移量不被缩放），而相机要的是 `s·(p − camX)`。
  > 写反会让整幅画面被顶偏 `camX×(scale−1)` 像素 —— 屏幕越宽越明显
  > （1920 宽时左侧一大块黑边、角色被推到 88% 处）。现在验收直接落到像素级：
  > 抓渲染时的真实 CTM + 抽样画布像素双重校验。
- **全局游戏速度**：设置面板五档 `0.5× / 0.75× / 1× / 1.25× / 1.5×`，
  整体时间缩放（物理 / 粒子 / 机关 / 敌人同步），即时生效，HUD 显示当前倍速。
- **道具密度可控**：单关 ≤ 40 个、相邻最小间距 ≥ 70 单位、平均 ≥ 0.6 秒一个；
  奶酪/金币/能力道具交错后统一分层铺开，不再扎堆。
- **横竖屏**：`matchMedia` 自动跟随 + 设置面板三态（自动 / 强制竖屏 / 强制横屏）。
  强制横屏优先 `requestFullscreen` + `screen.orientation.lock('landscape')`，
  失败降级为 CSS `rotate(90deg)` 交换宽高；URL 参数 `?orient=land` / `?orient=port`。
- **手机端专项优化**（本轮）：
  - **摇杆底座归位**：静止时停在**左下角拇指落点**（`left:84px; top:calc(100% - 88px)`），
    不再取热区正中（横屏会落到屏幕中左侧、视觉上压在角色身上，竖屏又离拇指太远）；
    触屏后底座仍跟随手指。
  - **横屏 HUD 限宽**：两条进度条 `flex: 1` 各占半屏太笨重，
    改 `flex: 0 1 200px`，群系标签跟得更近，把视野让给游戏区。
  - **竖屏转屏引导**：竖屏可视宽仅 323 世界单位（跑速 320/秒 → **只有 1 秒预警**），
    横屏 960（**3 秒**，差 3 倍），所以触屏竖屏菜单主动给引导卡
    「横屏体验好 3 倍 / 竖屏前方只有 1 秒视野，横屏是 3 秒」+「切到横屏」一键切。
  - **触屏说明分流**：触屏设备菜单只显示触屏操作说明，不再展示整块键盘键位表；
    桌面行为保持不变。
  - **触摸 UI 强制开关**：URL 参数 `?touch=1` / `?touch=0` 可强制开/关触摸 UI
    （桌面预览手机 UI、触屏笔记本只玩键盘、自动化测试都靠它）。
    判定顺序为 URL 参数 > 设置项 > 设备能力。
- **工程**：契约驱动（`src/contract.md` 为唯一事实源）的多子代理并行开发，
  五模块 `art / audio / fx / logic / ui` + 主线 `game`；模块缺失时 NOOP Proxy 兜底不崩。
- **存档**：`mr.save.v1`（进度）、`mr.cfg.v1`（设置）、`mr.records.v1`（最高分/最高关卡），
  支持导出/导入/清空。

## 开发

```sh
python3 build.py        # src/* → 单文件 index.html
node test/run.mjs       # 逻辑层回归
```

URL 参数：`?level=N`（直接进第 N 关）、`?seed=S`（指定种子复现关卡）、`?orient=land|port`、
`?touch=1|0`（强制开/关触摸 UI）。

  11 种危险物 / 4 种敌人 / 6 个群系、关卡确定性（同种子逐字段一致）、可通关性
  （断崖 ≤175、台阶抬升 ≤100、平台间距 ≤300、终点前 220px 无伤害机关）、
  1~50 关生成、六套计分、风格升降与衰减、连击衰减、碰撞落地、结算与星级。
- **UI 回归（ego-lite）**：**132 项全绿**，控制台全程零报错。
  - 第 1 轮（14 项）：六模块装载、主菜单、画布铺满、开局、关卡实体生成、物理推进着地。
  - 第 2 轮（45 项）：跳跃 / 冲刺 / 滑铲手感、**25 种道具逐个拾取与效果断言**、
    六套计分系统数值与 HUD 同屏可见、风格升级、暂停冻结与恢复、设置面板、
    竖屏 390×844 适配、**手动切换横屏**、关卡结算（星级 + 五项明细）、下一关、
    玩法说明图鉴（36 项）、命尽 Game Over。
  - 第 3 轮（24 项）：触屏设备识别、虚拟摇杆左右推动角色、三键（跳/冲/铲）生效、
    横屏 844×390 布局、小老鼠 9 种姿态程序化渲染、画布像素采样确认主角与道具着色、
    第 7/15/26/31/50 关群系循环与生成。
  - 第 4 轮（26 项）：**镜头安全带**（竖屏 / 横屏 / 桌面冲刺 90 帧逐帧采样，
    角色相对位置恒在 30%~60%、从不出画）、**渲染变换像素级校验**
    （真实 CTM 断言视口原点落在 (0,0)、背景左边缘在 x=0 无黑边、
    1920 宽屏下角色实际绘制坐标仍在 30%~60%）、**道具密度**（最小间距 ≥ 80 单位、
    平均间隔 ≥ 0.6 秒、单关 ≤ 40 个）、**速度控制**（0.5× / 1.5× 位移比实测、
    设置面板 5 档、HUD 倍速标记）。
    > 速度位移比原先测不准，根因不是倍速失效，而是**测量法被地形污染**：
    > 玩家起跑 3 秒后掉进坑里被卡住（`vx=0`），位移比飘到 1.69。
    > 现在改成与地形无关的运动学测量：取关卡最长连续平地 + 初速直接给到最大速度
    > （排除起步加速段）+ 窗口截到第一个道具之前（避开 catnip 的 +30% buff），
    > 位移比应严格等于倍速，实测 0.5 / 1.5 精确命中。
  - 第 5 轮（23 项，本轮新增·手机端专项）：触屏竖屏菜单出现横屏引导卡且文案含
    3 倍 / 1 秒 / 3 秒三组数字、引导卡带「切到横屏」按钮、点后确实进入横屏态、
    **摇杆底座落在左下角拇指位且不压画面中部**、横屏进度条限宽 200px 且实际宽度 < 半屏、
    **竖横屏视野量化对比**（横屏 ≥900 / 竖屏 ≤400 世界单位，横屏 ≥ 2 倍）、
    桌面端判定为非触屏且菜单显示键位表、**`?touch=1` 在桌面强制开触摸 UI**、
    **`?touch=0` 在触屏设备强制关触摸 UI 并改显示键盘说明**。
