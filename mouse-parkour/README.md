# 鼠族跑酷 · MOUSE RUSH

横版 2D 无限关卡跑酷 H5。主角是一只戴橙红围巾、背奶酪背包的灰色小老鼠，
在厨房 / 仓库 / 雨林 / 熔岩 / 冰原 / 虚空 六大场景之间无限跑酷。
手机竖屏、横屏双适配，**支持手动切换到横屏模式**。

## 玩法

- **移动**：桌面 `←/→` 或 `A/D`；移动端左半屏**动态虚拟摇杆**（手指按下处即原点）。
- **跳跃**：`空格` / `W` / `↑`（长按跳更高）；`Shift` / `J` **冲刺**（耗体力，冷却 0.55s）；
  `S` / `↓` **滑铲**（地面）或**跳劈**（空中）；`P`/`Esc` 暂停，`R` 重开本关，`M` 必杀。
- **核心手感**：coyote time（0.10s 离地宽限）、跳跃缓冲（0.12s）、可变跳跃高度、
  冲刺带残影与火焰尾迹、滑铲压低身形过矮道、踩敌弹起、极限落地硬直反馈。
- **无限关卡**：关卡程序化生成，同种子完全可复现；每 5 关切换一个场景，26 关后循环，
  难度系数随关卡线性上升（敌人速度/密度/机关密度/道具稀有度）。
- **每关 3 条命**，死亡回到本关检查点；命尽 Game Over，通关奖励 1 条命。
- **检查点**：每段开头一个，死亡后从最近检查点复活。

## 六套积分系统（同时在 HUD 可见）

| 系统 | 说明 |
|---|---|
| 主积分 | 距离分 + 拾取分 + 风格分 + 击杀分 + 过关奖励 |
| 金币 | 经济货币，拾取获得 |
| 奶酪 | 特殊收集物，决定关卡星级 |
| 风格分 | 靠动作累积，等级 D→C→B→A→S→SS，随时间衰减、可降级 |
| 连击 | 连续拾取/击杀不断链，倍率最高 ×4 |
| 能量 | 0-100 充能，满槽可放必杀「鼠王冲刺」清屏 |

**风格动作**（共 8 种，加分各不相同）：冲刺 +50、跳劈 +80、滑铲 +40、二段跳 +30、
踩敌 +120、极限落地 +60、擦弹 +20、空中连击 +10/段（上限 +60/跳）。

## 技术要点

- **单文件零外部资源**：`build.py` 把 `src/*` 拼成单文件 `index.html`；
  美术全为程序化 Canvas2D 预渲染精灵（主角小老鼠为实时程序化绘制，含 4 腿步态 /
  耳朵围巾飘动 / 9 种姿态），音效 27 个 cue + 5 轨 BGM 全 WebAudio 实时合成，
  特效全为 Canvas 粒子池。
- **打击感**：hitstop 冻结帧（受击 90ms / 击杀 55ms / 落地 25-45ms）、trauma² 震屏、
  受击白闪、伤害数字、连击弹窗、死亡慢动作 0.35x、必杀慢动作 0.5x、
  冲击缩放（camera zoom punch）、高速速度线、低命红晕、`navigator.vibrate`。
- **性能**：粒子对象池（硬上限 520，低画质 260）、离屏精灵预渲染、
  渐变发光（禁 `shadowBlur`，用径向渐变 + `lighter`）、DPR≤2、固定步长 60Hz 物理 + 累加器。
- **镜头跟随（硬约束）**：角色相对视口的位置被**锁在 35%~55% 区间**（目标 45%）。
  纯插值追赶在竖屏（可视宽仅 ~320 单位）缓冲不足，冲刺会把角色甩出画面；
  现在用「安全带夹紧」兜底，竖屏 / 横屏 / 桌面在任何速度下角色都不出画。
- **全局游戏速度**：设置面板五档 `0.5× / 0.75× / 1× / 1.25× / 1.5×`，
  整体时间缩放（物理 / 粒子 / 机关 / 敌人同步），即时生效，HUD 显示当前倍速。
- **道具密度可控**：单关 ≤ 40 个、相邻最小间距 ≥ 70 单位、平均 ≥ 0.6 秒一个；
  奶酪/金币/能力道具交错后统一分层铺开，不再扎堆。
- **横竖屏**：`matchMedia` 自动跟随 + 设置面板三态（自动 / 强制竖屏 / 强制横屏）。
  强制横屏优先 `requestFullscreen` + `screen.orientation.lock('landscape')`，
  失败降级为 CSS `rotate(90deg)` 交换宽高；URL 参数 `?orient=land` / `?orient=port`。
- **工程**：契约驱动（`src/contract.md` 为唯一事实源）的多子代理并行开发，
  五模块 `art / audio / fx / logic / ui` + 主线 `game`；模块缺失时 NOOP Proxy 兜底不崩。
- **存档**：`mr.save.v1`（进度）、`mr.cfg.v1`（设置）、`mr.records.v1`（最高分/最高关卡），
  支持导出/导入/清空。

## 开发

```sh
python3 build.py        # src/* → 单文件 index.html
node test/run.mjs       # 逻辑层回归
```

URL 参数：`?level=N`（直接进第 N 关）、`?seed=S`（指定种子复现关卡）、`?orient=land|port`。
