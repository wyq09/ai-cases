# luckin-coffee · 瑞幸咖啡小程序交互复刻

瑞幸咖啡微信小程序的高保真交互复刻（Web 版）。零依赖、纯静态，所有图形均由 CSS / 内联 SVG 程序化绘制，不使用任何品牌摄影素材。

## 预览

桌面浏览器打开 `index.html` 即可（居中手机壳展示，≤430px 视口自适应全屏）。建议使用移动端视口（390 × 844）获得最佳体验。

```bash
# 可选：本地起个静态服务
python3 -m http.server 8000
# 访问 http://localhost:8000/luckin-coffee/
```

## 页面与功能

**5 个主 Tab**（底部玻璃质感导航，`backdrop-filter` 毛玻璃 + 选中白胶囊）

- **首页** — Banner 轮播（自动播放 + 手势拖拽）、到店取/幸运送/即享咖啡入口、卡券/礼品卡/福利中心/手势抽奖、促销拼块、人气推荐横滑、AI Lucky 浮标
- **菜单** — 自提/外送切换、门店选择、优惠券横条、经典菜单/每周99起/我的常点、左侧分类栏与商品列表滚动联动、商品规格弹窗（温度/糖度/奶型加价）、飞入购物车动画、购物车面板（数量步进/清空/去结算）
- **即享** — 咖啡商城：分类筛选、商品网格、加购、浮动购物袋
- **会员卡（瑞王卡）** — 权益卡片、立减券领取、兑换券、月卡爆品宫格
- **我的** — 用户信息、优惠券/卡券/余额统计、订单面板（再来一单回填购物车）、服务中心、功能宫格、联名 Banner

**子页面**（右滑推入栈，支持返回）

- **确认订单** — 自提/外送异形 Tab（凹角圆弧）、门店/地址选择、超值换购、优惠明细、瑞王卡随单勾选、提交订单 → 取餐码成功页
- **配送方式** — 送货上门地址簿（单选回填订单）/ 门店自提列表
- **添加/编辑地址** — 表单校验、微信导入（模拟）、性别单选、标签 chips、默认地址开关、删除
- **门店列表 / 搜索** — 门店单选、热词与实时搜索

状态（购物车 / 地址簿 / 订单 / 门店）持久化于 `localStorage`，追加 `?reset=1` 可重置演示数据。

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建、无外部资源请求
- 饮品图 / 商品包装图均为参数化 SVG 生成（杯型 + 渐变液面 + 冰块 + 奶泡）
- 抽奖弹层基于 Canvas 手势轨迹检测

## 声明

本项目仅为前端学习与演示用途的 UI 交互复刻，与瑞幸咖啡官方无任何关联；页面文案与图形为演示自制，商品数据为虚构。请勿用于任何商业用途。
