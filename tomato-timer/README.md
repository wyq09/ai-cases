# tomato-timer · 番茄时钟

经典「番茄工作法」专注时钟 H5 复刻：奶油底色上一只手绘感的大番茄表盘，25 分钟专注、5 分钟休息循环推进，完成时以自定义铃声提醒。单文件、零外部资源，手机竖屏 / 横屏 / 桌面自适应，[在线体验](https://case.youyongai.com/tomato-timer/)。

## 玩法

- 点击「开始」进入专注倒计时，番茄轻微呼吸、绿叶轻摆；再点暂停，随时继续
- 「跳过」切换专注 / 休息阶段；右上角圆钮一键重置当前阶段
- 底部时长胶囊循环切换专注时长（15 / 20 / 25 / 30 / 45 分钟），休息时长在设置中调整
- 专注完成弹出结算卡片，自动累计当日番茄数与专注分钟数（本地保存，跨刷新不丢）
- 可选自动化：专注结束自动开始休息、休息结束自动开始专注、完成时手机振动
- 倒计时基于绝对时间戳驱动，切后台再回来自动校准，标签页标题实时同步剩余时间

## 提醒音频自定义

- 四种内置合成铃声：叮咚 / 清脆三连 / 小鸟啾啾 / 复古闹铃（WebAudio 程序化生成）
- 支持上传本地音频（mp3 / m4a / wav / ogg 等，≤15MB）作为完成提醒音，可试听、可删除
- 上传的音频保存在本机浏览器 IndexedDB，不会上传服务器；刷新后自动恢复
- 提醒音量独立滑杆，所有设置本地持久化

## 技术要点

- **单文件交付**：一个 `index.html`，全部图形为内联 SVG（番茄 / 叶片 / 高光 / 星点装饰），零外部请求
- **计时健壮**：`endTime` 时间戳驱动 + 200ms 轮询 + `visibilitychange` 校准，后台节流 / 跨天不漂移
- **iOS 兼容**：AudioContext 首次手势解锁、`svh` 单位 + `vh` 回退、safe-area 适配
- **自定义音频管线**：`decodeAudioData` 预解码 → IndexedDB 存 Blob → 启动时回读缓存 AudioBuffer

调试参数：`?reset=1` 清空本地设置与统计 · `window.TOMATO.state()` 读取运行状态
