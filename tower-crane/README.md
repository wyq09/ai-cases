# tower-crane 盖楼达人

经典「盖楼」小游戏复刻：吊机吊着集装箱房间左右摆动，点按松钩让房间落下，与楼下对齐越准分越高，偏得太多整块坠落；叠到目标层数即达标，可继续无尽挑战。单文件 H5，手机浏览器直接可玩。

## 玩法

- 点按屏幕松钩，房间垂直落下；对齐分四档：完美（吸附居中 + 连击加成）、很棒、悬险落住、坠落损一命
- **重心物理**：每个层间接口都会校验上方整段的重心是否落在支撑面内——越偏越险，失衡时塔身开始摇摆预警，重心出界上面整截轰然翻倒（掉 N 层 + 损一命），歪着叠高层必塌
- 完美连击分数递增，每 8 层里程碑 +1 命 +100 分；叠到目标 40 层达标，可转无尽模式继续冲高
- 塔越高吊机摆得越快、幅越大；进度自动存档，刷新后可「继续上楼」

## 技术要点

- **零依赖单文件**：`build.py` 把 `src/*.js` 拼进 shell 骨架（约 120KB），美术全 SVG dataURI、天空与城市离屏预渲染 + 缩小放大法柔焦，零外部资源离线可玩
- **纯逻辑模块**：摆动/判定/重心稳定性/计分/难度曲线独立成 `logic.js`，自带平衡性模拟器（玩家松钩时机误差 × 摆速人因放大 + 回中习惯模型），重心物理与倒塌规则实机/模拟共用一套代码，把 40 层目标调在普通玩家搏一搏的张力区
- **重心物理**：逐接口静力矩校验（上方分段质心 ∈ 相邻两块重叠支撑面），失稳从最靠顶接口整截切除并迭代复检；碎块刚体翻坠动画、失衡度驱动的塔顶摇摆与预警，可在设置面板整体关闭
- **每一块都能调**：游戏内配置面板——房间块配色增删改色、房间贴图/背景/吊钩图片上传替换、11 条音效逐条上传试听、25 项玩法参数滑杆、配置导出导入，改动即时生效
- **音画全程序化**：WebAudio 合成 10 条音效 + 马林巴五声音阶 BGM（分轨/duck/可见性暂停/自定义替换），粒子对象池 + 径向渐变辉光，DPR≤2
- **工程**：rAF + setInterval 双驱动防遮挡冻结、相机视差（云 0.12×/城市 0.4×）、file:// 进度与配置双键持久化
