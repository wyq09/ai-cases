# 数字华容道（slide-puzzle）

木质卡通风格滑块拼图（15-puzzle）H5 复刻。单文件、零外部资源、离线可玩、手机自适应。

## 玩法

- 点按与空格相邻的数字块使其滑入空格，也可直接在棋盘上滑动
- 把数字按 1、2、3… 顺序排好即获胜，用时与步数自动记录、按尺寸保存最佳纪录
- 「提示」自动归位一枚数字；长按「提示」自动演示完整解法（点棋盘可中断）
- 点中间牌匾切换 3×3 ~ 10×10；「重置」重新打乱
- 每一关的通关用时自动记录：按尺寸保存最佳纪录，帮助弹层可查最近战绩历史
- 六款俏皮主题色（原味木木 / 樱花朵朵 / 薄荷奶绿 / 海盐蓝蓝 / 香芋啵啵 / 蜜橘拿铁），一键换装
- 右上「⚙」直达设置；左上「←」打开玩法说明与战绩（内含设置入口）
- 上传一张照片可开启图片模式，把照片切进滑块玩照片拼图

## 技术要点

- **混合求解器**：n≤6 加权 A*（曼哈顿 + 线性冲突，贪心权重自适应）；n≥7 顺序归位求解器（planPair 双块 A* 处理行尾/列尾机动 + 残局 BFS），3×3~10×10 全部稳定可解，10×10 ≤70ms
- **奇偶校验洗牌**：随机排列后按 15-puzzle 可解性定理修正，保证每局必然可复原
- **全程序化资产**：SVG 图标与落叶、WebAudio 合成音效（木块 tock / 木琴琶音等 7 个 cue，支持自定义音频覆盖）、Canvas 粒子落叶雨（离屏预渲染精灵、对象池、无 shadowBlur）
- **持久化**：局面 / 步数 / 计时 / 最佳纪录 / 通关历史 localStorage 分 key 存储，刷新不丢；`?reset=1` 清档
- **自适应**：720×1280 设计稿整体缩放，竖屏 / 横屏 / 桌面全适配，触屏手势 + safe-area

## 开发

- `python3 build.py` 将 src/ 模块合并为单文件 index.html
- 调试参数：`?reset=1` 清档 · `?n=3~6` 选尺寸 · `?autoplay=1` 自动演示 · `?rig=one` 一步致胜 · `?muted=1` 静音
