# 地摊套圈 · Ring Toss Stall

1:1 复刻夜市地摊套圈摊位：红帐篷、黄字横幅（20个币20个圈 / 60个币100个圈）、红地毯上三排彩色矮凳摆着 9 种陶瓷玩偶奖品、格子衬衫老板头顶一叠彩虹圈。按住拖动瞄准、松手掷圈，套中就归你。

## 玩法

- **掷圈**：按住屏幕拖动——横向移动瞄准，上滑距离决定力度，松手掷出；辅助抛物线 + 落点圈可在设置里关掉（进阶模式）
- **经济**（照横幅）：20 币买 20 圈、60 币买 100 圈；初始送 20 币；币花完老板送 5 币（60s 冷却），无死局
- **奖品**：9 种奖品按前/中/后排摆放，越远越难套（物理噪声随距离放大 + 门槛收紧）；分值 1~10（白鹅→小火龙）
- **套中判定**：圈孔越过奖品颈部即套中；磕凳沿、砸奖品头会真实弹开；圈落地会弹跳、滚停、留在场上
- **图鉴**：套中收录图鉴；重复奖品自动折算成币（分值×50%）；套光 5 个摊主自动补货
- **老板**：掷圈/中奖/连败/买圈/补货随机吆喝；BGM 五声音阶弹拨 + 锣鼓点，全套 WebAudio 程序化合成

## 技术要点

- **单文件离线可玩**：`src/*.js` 模块 + `shell.html` + `build.py` 拼接，零外部资源；全部美术为 SVG dataURI、全部音效 WebAudio 合成
- **伪 3D 针孔投影**：世界坐标（米）+ 俯仰相机（`project(x,y,z)`），Canvas2D 画家算法排序渲染；圈是 even-odd 双椭圆 billboard，倾角随升降动态过渡
- **物理与判定共用一套代码**：固定步长 1/120 半隐式欧拉；闭式解落点预测（吸收积分系统偏差 g·t·dt/2）反解"拖哪落哪"；套颈/柱体侧碰/凳面/地面弹跳四种事件
- **蒙特卡洛校准**：`RT.LOGIC.simulate(n, σ, seed)` 与实机共用物理——3000×3 seed 定标普通玩家命中率 ~13%（前/中/后排 17/14/9，20 圈期望 1~3 中），避免力度饱和导致的难度倒挂
- **rAF + setInterval 双驱动**防后台节流冻结；可缺模块 NOOP Proxy 兜底；`?reset=1` 在读档前清档
- **测试钩子**：`window.__rt`（state/cfg/busy/throwRing/rig/setAuto/simulate）；URL 参数 `?rig=win|rare`、`?auto=N`、`?muted=1`

## 开发

```bash
python3 build.py            # 拼接 src/ → index.html
python3 test/serve.py 8790  # 本地禁缓存服务
ego-browser nodejs < test/regression.mjs   # 35 项回归
node -e "require('./src/logic.js').simulate(20000)"  # 命中率模拟
```

调试参数：`?reset=1` 清档 · `?rig=win|rare` 下圈必中 · `?auto=N` 自动掷 N 圈 · `?muted=1` 静音

## 测试情况

- 回归 35 项全绿（ego-browser 实测）：模块完整性、买圈/不足额、rig 普通与稀有必中、账目守恒、真实拖拽通路、轻点取消、自动 5 圈精确自停、领币冷却、图鉴渲染、面板改动生效+落盘、刷新持久化、3 视口无溢出、12 连掷浸泡零报错
- 数学：20000 次模拟总命中率 12.9%，分档 17.0/14.4/9.2，15/15 完美瞄准全中
