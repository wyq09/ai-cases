# 雷霆战机 · 银河防线

经典竖版飞行射击 H5 复刻：拖动战机、自动开火、躲避弹幕，击坠敌机与巨型 Boss，无限关卡递进。

## 玩法

- 拖动操控战机（灵敏度可调），自动开火；空格/炸弹钮清屏，P 暂停
- 6 级战机（突击者→灭世）机库购入、5 星升级；3 种僚机挂左右架，各自升级
- 无限关卡：敌军强度逐关提升（装甲/弹速/射速/密度四轴缩放），同关重打布局一致
- 关底 Boss 轮换 6 大原型 × 3 配色，三阶段弹幕 + 狂暴；击杀掉落部件
- 道具：火力 P / 炸弹 B / 修复 H / 护盾 S / 生命 L / 金币 / 部件，磁吸拾取
- 血条 + 备用机体系，坠机重生火力降档，命尽可花金币满血复活一次
- 计分：连击倍率（2.2s 窗口，上限 ×2）、擦弹加分、Boss 击杀与通关星级奖励
- 本地排行榜 top10、每关星级记录、战绩统计，刷新不丢

## 技术要点

- **单文件零外部资源**：全部美术为程序化 SVG dataURI（6 战机/6 敌机/18 Boss 变体/图标全套），音效 24 cue + 3 轨 BGM 全 WebAudio 合成，特效全 Canvas 粒子
- **打击感**：hitstop 冻结帧、trauma² 震屏、受击白闪、击退、伤害数字、擦弹火花、Boss 击杀慢动作连环爆、navigator.vibrate
- **性能**：子弹/敌机/粒子对象池、预渲染发光 sprite、禁 shadowBlur（径向渐变 + lighter）、DPR≤2、粒子硬上限 420、帧率自适应降档
- **工程**：契约驱动的多子代理并行开发（art/audio/fx/config-panel/enemy 五模块），build.py 拼接单文件；rAF + setInterval 双驱动防遮挡节流；NOOP Proxy 兜底可缺模块
- 游戏内设置面板：战机立绘/音效上传替换、玩法参数、BGM/SFX 音量、存档导出导入
- AI 演示模式（`?demo=1`）自动躲避/拾取/开火，可挂机推关

## 开发

```sh
python3 build.py   # src/*.{css,js} → 单文件 index.html
```

调试参数：`?reset=1` 清档 · `?demo=1` AI 演示 · `?level=N` 直达关卡 · `?god=1` 无敌 · `?muted=1` 静音 · `?boot=hangar|levels` 指定首屏；`window.__tf` 调试钩子。
